# 《pdf转md》

## 核心原则

将 PDF 页面转换为适合 Obsidian 阅读的 Markdown 忠实转写稿。保留原文顺序、层级和原意。可以校订识图误读和整理格式，但不得总结、扩写、添加原文没有的标题，也不得把原文改写成学习笔记提纲，除非用户明确要求。

默认只处理 PDF。输出文件放到用户指定目录；若用户沿用本 vault 习惯，则从 `pdf` 文件夹读取新 PDF，输出到 `待排版`，文件名使用 `<原 PDF 文件名>_模型识图.md`。

如果用户明确要求调用“国网笔记小助手”，再叠加该助手的笔记风格、教材归属和考点标记。否则，本技能始终保持“忠实转写”模式。

## 默认处理流程

1. 确认 PDF 来源和 Markdown 输出目录。
2. 扫描 PDF 或图片型 PDF：先将 PDF 渲染为逐页图片，再使用模型视觉能力逐页识别、校订和转写。
3. 不要默认运行 OCR 脚本，不要把 OCR 文本作为主转写来源；只有用户明确要求 OCR、模型视觉不可用，或需要辅助核对时，才可使用 OCR 作为旁证。
4. 保持页码和页面顺序不变。多栏页面需按自然阅读顺序重建文本。
5. 只转换 PDF 中可见的原始结构：
   - 可见章节标题转为 Markdown 标题；
   - 可见列表转为 Markdown 列表；
   - 单元格结构清楚的表格转为 Markdown 表格；
   - 原文没有标题的普通段落保持正文格式；
   - 图号、图题、例题编号、习题编号按原文顺序保留。
6. 转写完成后，遍历全部文字，对重要术语、设备名称、定义、变量和电气工程关键词加粗，但不改变句子含义。
7. 最后检查公式、单位、符号、页码和不确定标记是否一致。

## Markdown 规则

- 使用 Obsidian Flavored Markdown，确保阅读视图能正常渲染。
- 每个独立公式块前后都保留空行。
- 仅对 vault 内部笔记使用 wikilink；外部网址使用普通 Markdown 链接。
- 对阅读视图中需要隐藏的不确定内容，使用 Obsidian 注释：

```markdown
%% 不确定：原图此处模糊，需对照原 PDF。 %%
```

- 如果必须进行尽力还原，使用可见标记：

```markdown
[原文模糊：推测出的内容]
```

- 如果图片、相量图、波形图、特性曲线或等效电路无法忠实转换，保留图号或图题。只有在用户要求重新生成图形时，才添加 Python 绘图提示词。

## 电气工程公式规则

- 所有变量、参数、向量、相量、复数和单位都使用 LaTeX。
- 短变量和短表达式使用行内公式，例如 `$P_e$`、`$kV$`、`$MVA$`、`$\Omega$`、`$E = U + I(R + jX)$`。
- 独立推导或较长公式使用公式块：

```markdown
$$
S = \sqrt{3}UI
$$
```

- 相量默认使用点号表示，除非原文明确采用其他记号，例如 `$\dot{U}$`、`$\dot{I}$`、`$\dot{E}$`。
- 保留原文可见的下标、上标和相别标记，例如 `$U_{ab}$`、`$I_a$`、`$X_d'$`、`$x_d''$`。
- 单位按原文和电气工程惯例保持一致，例如 `$kV$`、`$A$`、`$MVA$`、`$MW$`、`$Mvar$`、`$\Omega$`、`$pu$`。
- 如果公式不清楚，不要擅自规范化。用 `[原文模糊：...]` 或 Obsidian 不确定注释标记。

## 模型识图校正规则

- 根据页面图像、上下文和电气工程逻辑修正明显识别错误。
- 所有非显然推断都必须标注。例如：
  - `[原文模糊：继电保护装置]`
  - `%% 推断修正：图中文字较糊，已按上下文将其校为“磁阻”。 %%`
- 当概念、数字、标准或教材细节不能完全确定时，必须写明：`我不清楚这一点的准确定义，请参考原教材确认`。
- 如果 PDF 引用了现行国家标准，例如 GB/T，且需要插入标准的准确文本，应先查找可靠来源。否则，只保留 PDF 中可见内容，并标注不确定。

## 禁止输出

- 不生成一句话摘要、复习总结、考点提炼或 AI 解释。
- 不添加 PDF 中没有出现的标题。
- 不为了美观而重排内容顺序。
- 不把原文替换成教材式改写。
- 不把不确定的识图内容强行写成确定陈述。
- 不默认使用 OCR 脚本或 OCR 缓存。
- 不把截图作为本技能的默认输入；本技能以 PDF 为主。如果用户提供图片，只作为页面证据辅助处理，或询问是否扩展流程。

## 验收清单

- Markdown 看起来像 PDF 的清理版转写稿，而不是新的解释。
- 原文可见的标题、列表、公式、表格、图名、图题均按顺序保留。
- 电气公式和单位能在 Obsidian 中以 LaTeX 正常渲染。
- 重要术语在转写后已加粗。
- 所有不确定或推断内容均已标注。
- 没有加入原文不存在的摘要、新标题或考点标签。
