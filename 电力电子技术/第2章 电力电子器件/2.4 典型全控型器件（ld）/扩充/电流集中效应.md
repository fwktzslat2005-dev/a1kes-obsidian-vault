# 一、定义

**电流集中效应**（Current Crowding / 电流集边效应）是指：在功率半导体器件（尤其是 GTR）中，由于局部温度升高导致该区域导电能力增强、电流进一步向该区域集中、最终形成**热点**并可能烧毁器件的现象。

# 二、正反馈链条

$$I \uparrow \;\rightarrow\; P = I^2 R \uparrow \;\rightarrow\; T \uparrow \;\rightarrow\; U_{BE} \downarrow \;\rightarrow\; I \uparrow \;\rightarrow\; \cdots \;\rightarrow\; \text{热击穿}$$

## 每一步的含义

| 环节 | 原因 |
|------|------|
| $I \uparrow$ | 局部电流开始增大（可能因工艺不均匀、外部扰动） |
| $T \uparrow$ | 功耗 $P = I^2 R$ 增大，局部发热 |
| $U_{BE} \downarrow$ | GTR 的 $U_{BE}$ 具有**负温度系数**（约 $-2\text{ mV/°C}$），温度越高，开启电压越低 |
| $I \uparrow$（循环） | 同一 $U_{BE}$ 下，温度更高的区域注入电流更大——**正反馈形成** |

> [!danger] **核心机制**
> 双极型器件的 $U_{BE}$ 是**负温度系数**的：$$\frac{\mathrm{d}U_{BE}}{\mathrm{d}T} \approx -2 \text{ mV/°C}$$
> 这意味着温度越高，发射结越容易导通，电流越往热的地方"挤"——**雪上加霜的正反馈**。

# 三、为什么会有热点？

GTR 芯片面积大，各处温度不可能**绝对均匀**：

- 某个区域温度稍高 $\rightarrow$ $U_{BE}$ 略低 $\rightarrow$ 分走的电流更多 $\rightarrow$ 更热
- 电流像滚雪球一样往这个"热点"集中
- 最终**所有电流挤在一个小点上**，局部温度瞬间飙升 $\rightarrow$ **烧毁**

# 四、与二次击穿的关系

[[2.4.2 电力晶体管 B类考点#2. 二次击穿|GTR 的二次击穿]]的根本原因就是电流集中效应：

1. 一次击穿（雪崩击穿）发生后，$I_c$ 增大
2. 若不有效限制电流，电流集中效应开始起作用
3. 热点形成 $\rightarrow$ 电流集中加剧 $\rightarrow$ **二次击穿**
4. 二次击穿 → 器件**永久损坏**

> [!summary] **热稳定性差的本质**
> GTR（BJT）的热稳定性差，根源就是 $U_{BE}$ 的负温度系数导致的**电流集中正反馈**。

# 五、对比：为什么 MOSFET 没有这个问题？

| 特性 | GTR (BJT) | 功率 MOSFET |
|------|-----------|-------------|
| 温度系数 | **负温度系数**（$U_{BE} \downarrow$） | **正温度系数**（$R_{DS(on)} \uparrow$） |
| 温度升高时 | 电流增大，更热 $\Rightarrow$ 恶性循环 | 电阻增大，电流减小 $\Rightarrow$ 自限流 |
| 并联均流 | ❌ 需要额外均流措施 | ✅ 天生**自均流** |
| 热稳定性 | **差** | **好** |

> [!tip] **一句话记**
> GTR 越热越能导电（负温度系数），电流往热点集中→烧毁；MOSFET 越热越不能导电（正温度系数），电流自动分散→安全。这就是 GTR **热稳定性差**的根本原因。
