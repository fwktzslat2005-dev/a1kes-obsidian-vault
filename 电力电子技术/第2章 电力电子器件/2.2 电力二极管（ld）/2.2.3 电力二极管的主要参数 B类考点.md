# 一、正向平均电流 $I_{\text{F(AV)}}$
1.  **定义**：
	- **正向平均电流** $I_{\text{F(AV)}}$ 是指电力二极管长期运行时，在指定的管壳温度和散热条件下，其允许流过的**最大工频正弦半波电流的平均值**。这也是标称其**额定电流**的参数。
2. **含义**：
	- 如果某电力二极管的正向平均电流为 $I_{\text{F(AV)}}$，即它允许流过的最大工频正弦半波电流的平均值为 $I_{\text{F(AV)}}$，由正弦半波波形的平均值与有效值的关系为 $1 : 1.57$ 可知，该电力二极管允许流过的最大电流**有效值**为 $1.57 I_{\text{F(AV)}}$。
		- $$i=I_\text{m}\sin\omega t$$
		- 平均值：$$I_\text{AV} = \frac{1}{2\pi}\int_0^\pi{I_m\cdot}\sin\omega t \, \mathrm{d}(\omega t)=I_\text{m}$$
		- 有效值$$I = \sqrt{\frac{1}{2\pi}\int_0^\pi({I_m\cdot}\sin\omega t)^{2} \, \mathrm{d}(\omega t)}=\frac{I_\text{m}}{2}$$
		- $$K_\text{AV}=\frac{I}{I_\text{AV}}=\frac{\pi}{2}=1.57$$
3. **使用者选取**：
	- 如果已知某电力二极管在电路中需要流过某种波形电流的**有效值**为 $I_{\text{D}}$，则至少应该选取额定电流 (**正向平均电流 $I_{\text{F(AV)}}$**)为 $I_{\text{D}} / 1.57$ 的电力二极管，当然还要考虑一定的**裕量**。
# 二、正向压降 $U_{\text{F}}$
- **正向压降** $U_{\text{F}}$ 指电力二极管在指定温度下，流过某一指定的稳态正向电流时对应的**正向压降**。
- 有时候，其参数表中也给出在指定温度下流过某一瞬态正向大电流时，电力二极管的**最大瞬态正向压降**。
# 三、反向重复峰值电压 $U_{\text{RRM}}$
- **反向重复峰值电压** $U_{\text{RRM}}$ 指对电力二极管所能**重复施加的反向最高峰值电压**。通常是其**雪崩击穿电压** $U_{\text{B}}$ *的 2/3*。
- 使用时，往往按照电路中电力二极管可能承受的反向最高峰值电压的*两倍*来选定此项参数。
# 四、反向恢复时间 $t_{\text{rr}}$
- **反向恢复时间**包括延迟时间与电流下降时间，即：
$$t_{\text{rr}} = t_{\text{d}} + t_{\text{f}}$$
# 五、最高工作结温 $T_{\text{JM}}$
- **结温**是指管芯 $\text{PN}$ 结的平均温度，用 $T_{\text{j}}$ 表示。$T_{\text{JM}}$ 是指在 $\text{PN}$ 结不致损坏的前提下所能承受的**最高平均温度**。
- $T_{\text{JM}}$ 通常在 125~175°C 范围之内。
# 六、浪涌电流 $I_{\text{FSM}}$
- **浪涌电流** $I_{\text{FSM}}$ 指电力二极管所能承受最大的连续一个或几个工频周期的**过电流**。
