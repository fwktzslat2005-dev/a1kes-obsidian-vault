# 一、结构
![[图2-5 电力二极管的外形、基本结构和电气图形符号.jpg|center]]
- 图 2-10 所示为晶闸管的外形、结构和电气图形符号。
## 1. 外形
- 晶闸管也主要有**螺栓形**和**平板形**两种封装结构，均引出**阳极 A**、**阴极 K** 和**门极（控制端）G** 三个连接端。
## 2. 内部结构
- 晶闸管内部是 **$\text{PNPN}$ 四层半导体结构**，分别命名为 $P_1$、$N_1$、$P_2$、$N_2$ 四个区。
- $P_1$ 区引出阳极 $\text{A}$，$N_2$ 区引出阴极 $\text{K}$，$P_2$ 区引出门极 $\text{G}$，四个区形成 $J_1$、$J_2$、$J_3$ 三个 **$\text{PN}$ 结**。
## 3. 门极可控开通及单向导电特性
 - 当门极开路时，则有：
	1. 如果**正向电压**（阳极高于阴极）加到器件上，则 $J_2$ 处于**反向偏置状态**，器件 $\text{A}$、$\text{K}$ 两端之间处于**阻断状态**，只能流过很小的漏电流。
	2. 如果**反向电压**加到器件上，则 $J_1$ 和 $J_3$ **反偏**，该器件也处于**阻断状态**，仅有极小的**反向漏电流**通过。
# 二、工作原理
## 1. 双晶体管模型
- 晶闸管导通的工作原理可以用**双晶体管模型**来解释，如图 2-11 所示。![[图2-11 晶闸管的双晶体管模型及其工作原理.png|center|409]]
- 如果在器件上取一倾斜的截面，则晶闸管可以看作由 $P_1 N_1 P_2$ 和 $N_1 P_2 N_2$ 构成的两个晶体管 $\text{VT1}$（$\text{PNP}$ 型）和 $\text{VT2}$（$\text{NPN}$ 型）组合而成。
## 2. 导通过程
1. 如果外电路向门极注入电流 $I_{\text{G}}$，也就是注入**驱动电流**。
2. $I_{\text{G}}$ 流入晶体管 $\text{VT2}$ 的基极，即产生集电极电流 $I_{\text{c2}}$。
3. $I_{\text{c2}}$ 构成晶体管 $\text{VT1}$ 的基极电流，放大成集电极电流 $I_{\text{c1}}$。
4. $I_{\text{c1}}$ 又进一步增大 $\text{VT2}$ 的基极电流。
- 如此形成强烈的**正反馈**，最后 $\text{VT1}$ 和 $\text{VT2}$ 进入**完全饱和状态**，即**晶闸管导通**。
>[!note] **注**：
此时如果撤掉外电路注入门极的电流 $I_{\text{G}}$，晶闸管由于内部已形成了强烈的**正反馈**会**仍然维持导通状态**。
## 3. 关断的条件
- 若要使晶闸管关断，必须：
	1. **去掉阳极所加的正向电压**；
	2. 或者**给阳极施加反压**；
	3. 或者设法使流过晶闸管的电流**降低到接近于零的某一数值以下**，晶闸管才能关断。
## 4. 可能被触发导通的情况
1. 阳极电压升高至相当高的数值造成**雪崩效应**(*正向击穿*)。
2. 阳极电压上升率 $\mathrm{d}u/\mathrm{d}t$ **过高**。
3. **结温较高**$\Rightarrow$ *热击穿*
4. 光直接照射硅片，即**光触发**。

>[!note] **注**：
这些情况除了由于**光触发**可以保证控制电路与主电路之间的良好绝缘而应用于高压电力设备之中之外，其他都因**不易控制**而难以应用于实践。

- **结论**：只有**门极触发**是最精确、迅速而可靠的控制手段。
