## 1.1 核心对比表

### 1.1.1 脉波数与输出来源速览

| 电路 | 脉波数 | 输出电压来源 | 应用特点 |
|---|---:|---|---|
| **单相半波可控整流电路** | $m=1$ | 单相电压正半周 | 结构简单，但**输出脉动大**、应用较少（重要考点） |
| **单相桥式全控整流电路** | $m=2$ | 单相正、负半周均整流输出 | 单相整流中应用较多，变压器利用率高（核心重点） |
| **单相全波可控整流电路** | $m=2$ | 中心抽头变压器二次侧两个半绕组交替供电 | 晶闸管少、管压降少，但需中心抽头，晶闸管承受电压较高 |
| **单相桥式半控整流电路** | $m=2$ | 晶闸管与二极管组成桥式回路 | 电阻负载与全控相同；阻感负载可能出现**失控**，加续流二极管可改善（常考） |
| **三相半波可控整流电路** | $m=3$ | 三相相电压正半周包络线 | 脉动频率 $150\text{Hz}$，因二次电流含直流分量而应用较少（重要考点） |
| **三相桥式全控整流电路** | $m=6$ | 三相线电压正半周包络线 | 脉动频率 $300\text{Hz}$，应用最广（核心重点） |

| 电路 | 电阻负载公式 | 阻感/连续输出公式 |
|---|---|---|
| **单相半波可控整流电路** | $U_d=0.45U_2\dfrac{1+\cos\alpha}{2}$ | 无续流时需按导通区间积分；带续流二极管时波形不再出现负值 |
| **单相桥式全控整流电路** | $U_d=0.9U_2\dfrac{1+\cos\alpha}{2}$ | $U_d=0.9U_2\cos\alpha$ |
| **单相全波可控整流电路** | 从直流输出端看与单相桥式全控基本一致 | 从直流输出端看与单相桥式全控基本一致 |
| **单相桥式半控整流电路** | 与单相桥式全控相同 | 源笔记未给出统一总表 |
| **三相半波可控整流电路** | 连续时 $U_d=1.17U_2\cos\alpha$；断续时 $U_d=0.675U_2\left[1+\cos\left(30^\circ+\alpha\right)\right]$ | $U_d=1.17U_2\cos\alpha$ |
| **三相桥式全控整流电路** | 连续时 $U_d=2.34U_2\cos\alpha$；断续时 $U_d=2.34U_2\left[1+\cos\left(60^\circ+\alpha\right)\right]$ | $U_d=2.34U_2\cos\alpha$ |

| 电路 | 负载类型 | 触发角移相范围 | 晶闸管导通角 |
|---|---|---|---|
| **单相半波可控整流电路** | 电阻负载 | $0^\circ\sim180^\circ$ | $\theta=\pi-\alpha$ |
| **单相半波可控整流电路** | 带续流二极管阻感负载 | $0^\circ\sim180^\circ$ | 晶闸管 $\theta=\pi-\alpha$；续流二极管 $\theta=\pi+\alpha$ |
| **单相桥式全控整流电路** | 电阻负载 | $0^\circ\sim180^\circ$ | $\theta=\pi-\alpha$ |
| **单相桥式全控整流电路** | 阻感负载连续 | $0^\circ\sim90^\circ$ | $\theta=180^\circ$ |
| **单相全波可控整流电路** | 对应负载 | 与对应单相桥式全控情况基本一致 | 与对应单相桥式全控情况基本一致 |
| **单相桥式半控整流电路** | 阻感负载 | 源笔记未给出统一总表 | 需结合续流/失控状态判断 |

| **三相桥式全控整流电路** | 阻感负载 | $0^\circ\sim90^\circ$ | $120^\circ$ |

### 1.1.4 单个电路速查卡片

> [!note]- 单相半波可控整流电路
> **脉波数**：$m=1$。
> **关键公式**：电阻负载 $U_d=0.45U_2\dfrac{1+\cos\alpha}{2}$。
> **移相/导通角**：电阻负载 $0^\circ\sim180^\circ$，$\theta=\pi-\alpha$；带续流二极管阻感负载的移相范围也是 $0^\circ\sim180^\circ$。
> **易错点**：变压器二次侧电流含直流分量，存在**直流磁化**问题；输出脉动大，应用较少。（重要考点）

> [!note]- 单相桥式全控整流电路
> **脉波数**：$m=2$。
> **关键公式**：电阻负载 $U_d=0.9U_2\dfrac{1+\cos\alpha}{2}$；阻感负载连续 $U_d=0.9U_2\cos\alpha$。
> **移相/导通角**：电阻负载 $0^\circ\sim180^\circ$，$\theta=\pi-\alpha$；阻感负载连续 $0^\circ\sim90^\circ$，$\theta=180^\circ$。
> **易错点**：正、负半周均有整流输出，是**双脉波整流电路**；变压器二次绕组电流平均值为零，无直流磁化问题。（核心重点）

> [!note]- 单相全波可控整流电路
> **脉波数**：$m=2$。
> **关键公式**：从直流输出端看，与单相桥式全控基本一致。
> **移相/导通角**：与对应单相桥式全控情况基本一致。
> **易错点**：需要中心抽头变压器；晶闸管数量少、管压降少，但晶闸管承受的最大电压比单相全控桥高。

> [!note]- 单相桥式半控整流电路
> **脉波数**：$m=2$。
> **关键公式**：电阻负载时与单相桥式全控相同；阻感负载统一平均电压表达式源笔记未明确。
> **移相/导通角**：源笔记未给出统一总表，需结合续流/失控状态判断。
> **易错点**：阻感负载下可能出现**失控**；加续流二极管后，续流期间 $u_d=0$，可改善工作状态。（常考）

> [!note]- 三相半波可控整流电路
> **脉波数**：$m=3$，脉动频率 $150\text{Hz}$。
> **关键公式**：连续输出 $U_d=1.17U_2\cos\alpha$；电阻负载断续时 $U_d=0.675U_2\left[1+\cos\left(30^\circ+\alpha\right)\right]$。
> **移相/导通角**：电阻负载 $0^\circ\sim150^\circ$；阻感负载 $0^\circ\sim90^\circ$；连续时 $\theta=120^\circ$。
> **易错点**：输出电压来自三相**相电压**正半周包络线；变压器二次电流含直流分量，应用较少。（重要考点）

> [!note]- 三相桥式全控整流电路
> **脉波数**：$m=6$，脉动频率 $300\text{Hz}$。
> **关键公式**：连续输出 $U_d=2.34U_2\cos\alpha$；电阻负载断续时 $U_d=2.34U_2\left[1+\cos\left(60^\circ+\alpha\right)\right]$。
> **移相/导通角**：电阻负载 $0^\circ\sim120^\circ$；阻感负载 $0^\circ\sim90^\circ$；连续时 $\theta=120^\circ$。
> **易错点**：输出电压来自三相**线电压**正半周包络线；任意时刻共阴极组和共阳极组各有一只晶闸管导通；应用最广。（核心重点）

> [!note] 说明
> 本节只整理源笔记中已经明确出现的结论。对“单相桥式半控整流电路”的统一导通角、统一平均电压表达式与直流分量结论，当前源笔记没有给出完整总表；我不清楚这一点的准确定义，请参考原教材确认。

# 二、相同点整理

## 1. 都通过触发角 $\alpha$ 控制输出平均电压

- **可控整流电路**的共同特征是：改变晶闸管的**触发角** $\alpha$，即可改变直流侧输出电压平均值 $U_d$。（核心重点）
- 在典型连续输出公式中，$U_d$ 常随 $\cos\alpha$ 变化：

$$
U_d=K U_2\cos\alpha
$$

- 不同电路的系数 $K$ 不同：
	- 单相桥式全控阻感连续：$K=0.9$；
	- 三相半波连续：$K=1.17$；
	- 三相桥式全控连续：$K=2.34$。

## 2. 电阻负载下 $i_d$ 与 $u_d$ 波形一致

- **电阻负载**满足电压与电流成正比，因此 $i_d$ 与 $u_d$ 波形形状相同。（常考）
- 当电阻负载下电流断续时，晶闸管电流降为零即关断，输出电压 $u_d$ 不再继续跟随负半周，因此一般**不出现负值部分**。

## 3. 阻感负载下电感使电流不能突变

- **阻感负载**中，电感 $L$ 对电流变化有抑制作用，使 $i_d$ 不能突变。（核心重点）
- 当 $L$ 足够大时，负载电流 $i_d$ 可近似为一条水平线。
- 阻感负载会延长晶闸管导通时间，可能使 $u_d$ 波形出现**负的部分**，使平均值 $U_d$ 下降。（重要考点）

## 4. 脉波数越多，输出脉动越小

- 单相半波：一周期脉动 $1$ 次，脉动最大。
- 单相桥式全控、单相全波：一周期脉动 $2$ 次。
- 三相半波：一周期脉动 $3$ 次，脉动频率为 $150\text{Hz}$。
- 三相桥式全控：一周期脉动 $6$ 次，脉动频率为 $300\text{Hz}$。

> [!important] 考点抓手
> 从“单相半波 $\rightarrow$ 单相桥式/全波 $\rightarrow$ 三相半波 $\rightarrow$ 三相桥式全控”，脉波数整体增大，输出电压脉动减小，滤波更容易。（核心重点）

# 三、异同点对比

## 1. 单相整流与三相整流

| 对比项 | 单相可控整流 | 三相可控整流 |
|---|---|---|
| 交流侧电源 | 单相电源 | 三相电源 |
| 适用场景 | 容量较小、结构较简单 | 负载容量较大，要求直流电压脉动较小、容易滤波 |
| 典型脉波数 | $m=1$ 或 $m=2$ | $m=3$ 或 $m=6$ |
| 输出平滑程度 | 脉动较大 | 脉动较小 |
| 典型代表 | 单相桥式全控 | 三相桥式全控 |

- **三相桥式全控整流电路**在各种整流电路中应用最广，因为其输出脉动小、变压器二次侧无直流磁化问题、适合较大容量负载。（核心重点）

## 2. 半波与桥式/全波

| 对比项 | 半波整流 | 桥式/全波整流 |
|---|---|---|
| 利用交流半周 | 主要利用一个方向的半周 | 正、负半周均可向负载供电 |
| 脉波数 | 较少 | 较多 |
| 变压器二次电流 | 易含直流分量 | 正负方向对称时平均值为零 |
| 主要缺点 | 输出脉动大、直流磁化 | 器件数量或变压器结构要求增加 |

- **单相半波**与**三相半波**都要特别注意变压器二次侧电流中的**直流分量**问题。（重要考点）
- **单相桥式全控**、**单相全波**、**三相桥式全控**从交流输入侧或变压器二次侧看，电流平均值为零，通常无直流磁化问题。

## 3. 电阻负载与阻感负载

| 对比项 | 电阻负载 | 阻感负载 |
|---|---|---|
| 电流波形 | $i_d$ 与 $u_d$ 形状相同 | $i_d$ 受电感影响更平直 |
| 电流连续性 | 随 $\alpha$ 增大容易断续 | $L$ 足够大时可连续 |
| $u_d$ 负值部分 | 断续后 $u_d$ 为零，通常不出现负值 | 续流作用可能使 $u_d$ 出现负值 |
| 移相范围 | 可大于阻感连续时范围 | 一般到 $90^\circ$ 时 $U_d=0$ |

- 电阻负载考查重点：**何时连续、何时断续、断续后导通角如何变化**。
- 阻感负载考查重点：**电感续流使电流连续，$u_d$ 可出现负值，$U_d$ 随 $\alpha$ 增大而下降**。（核心重点）

## 4. 全控与半控

| 对比项  | 全控整流电路       | 半控整流电路             |
| ---- | ------------ | ------------------ |
| 器件组成 | 全部受控器件为晶闸管   | 晶闸管与二极管混合          |
| 控制能力 | 正、负半周均由晶闸管控制 | 控制能力弱于全控           |
| 电阻负载 | 可按触发角调压      | 单相桥式半控与全控工作情况相同    |
| 阻感负载 | 可按换流规律分析     | 不带续流二极管时可能出现**失控** |

- 单相桥式半控在阻感负载下，若触发角突然增大到 $180^\circ$ 或触发脉冲丢失，可能出现一个晶闸管持续导通、两个二极管轮流导通的**失控现象**。（常考）
- 加续流二极管后，续流期间 $u_d=0$，可避免 $u_d$ 出现负值部分，改善电路工作状态。

## 5. 三相半波与三相桥式全控

| 对比项 | 三相半波可控整流 | 三相桥式全控整流 |
|---|---|---|
| 输出电压组成 | 三相**相电压**正半周包络线 | 三相**线电压**正半周包络线 |
| 脉波数 | $m=3$ | $m=6$ |
| 脉动频率 | $150\text{Hz}$ | $300\text{Hz}$ |
| 连续输出公式 | $U_d=1.17U_2\cos\alpha$ | $U_d=2.34U_2\cos\alpha$ |
| 晶闸管导通 | 每次一只晶闸管导通 | 任意时刻共阴极组、共阳极组各一只晶闸管导通 |
| 变压器直流分量 | 有 | 无 |
| 应用 | 较少 | 最广泛 |

- 三相桥式全控需要**两个晶闸管同时导通**才能形成负载供电回路，其中一个来自共阴极组，一个来自共阳极组，且不能为同一相上下桥臂。（重要考点）
- 三相桥式全控触发脉冲按 $VT_1\rightarrow VT_2\rightarrow VT_3\rightarrow VT_4\rightarrow VT_5\rightarrow VT_6$ 顺序，相位依次相差 $60^\circ$。

# 四、易混考点速记

## 1. 移相范围对比

| 电路与负载 | 移相范围 |
|---|---|
| 单相半波，电阻负载 | $0^\circ\sim180^\circ$ |
| 单相半波，带续流二极管阻感负载 | $0^\circ\sim180^\circ$ |
| 单相桥式全控，电阻负载 | $0^\circ\sim180^\circ$ |
| 单相桥式全控，阻感负载连续 | $0^\circ\sim90^\circ$ |
| 三相半波，电阻负载 | $0^\circ\sim150^\circ$ |
| 三相半波，阻感负载 | $0^\circ\sim90^\circ$ |
| 三相桥式全控，电阻负载 | $0^\circ\sim120^\circ$ |
| 三相桥式全控，阻感负载 | $0^\circ\sim90^\circ$ |

## 2. 导通角速记

| 情况 | 导通角结论 |
|---|---|
| 单相半波，电阻负载 | $\theta=\pi-\alpha$ |
| 单相桥式全控，电阻负载 | $\theta=\pi-\alpha$ |
| 单相桥式全控，阻感负载连续 | $\theta=180^\circ$ |
| 三相半波，连续输出 | $\theta=120^\circ$ |
| 三相半波，电阻负载断续 | $\theta=150^\circ-\alpha$ |
| 三相桥式全控，连续输出 | $\theta=120^\circ$ |
| 三相桥式全控，电阻负载断续 | $\theta=2(120^\circ-\alpha)$ |

## 3. 公式速记

$$
\text{单相半波电阻负载：}\quad U_d=0.45U_2\frac{1+\cos\alpha}{2}
$$

$$
\text{单相桥式全控电阻负载：}\quad U_d=0.9U_2\frac{1+\cos\alpha}{2}
$$

$$
\text{单相桥式全控阻感连续：}\quad U_d=0.9U_2\cos\alpha
$$

$$
\text{三相半波连续输出：}\quad U_d=1.17U_2\cos\alpha
$$

$$
\text{三相桥式全控连续输出：}\quad U_d=2.34U_2\cos\alpha
$$

> [!tip] 记忆方法
> 连续输出时，三相桥式全控的 $U_d$ 系数 $2.34$ 是三相半波 $1.17$ 的 2 倍；单相桥式全控的最大平均电压 $0.9U_2$ 是单相半波 $0.45U_2$ 的 2 倍。（核心重点）

## 4. 直流磁化速记

- **有直流分量**：单相半波、三相半波。
- **无直流分量**：单相桥式全控、单相全波、三相桥式全控。
- 判断口诀：凡是二次侧电流只偏向一个方向，容易有**直流磁化**；正、反两个方向对称流过时，平均值为零。

## 5. 断续临界点速记

| 电路 | 电阻负载连续/断续临界 |
|---|---|
| 三相半波 | $\alpha=30^\circ$ |
| 三相桥式全控 | $\alpha=60^\circ$ |

- 三相半波电阻负载：$0^\circ\sim30^\circ$ 连续，$30^\circ\sim150^\circ$ 断续。
