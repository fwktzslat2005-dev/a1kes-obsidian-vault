# 一、逆变角
- 为分析和计算方便起见，通常把 $\alpha > \pi/2$ 时的控制角用 $\pi - \alpha = \beta$ 表示， $\beta$ 称为**逆变角**。
# 二、基本数量关系
- **直流侧输出电压平均值**：
$$U_{\text{d}} = 2.34 U_2 \cos\alpha = -2.34 U_2 \cos\beta$$
- **输出直流电流的平均值**：
$$I_{\text{d}} = \frac{U_{\text{d}} - E_{\text{M}}}{R}$$
- 在**逆变状态**时， $U_{\text{d}}$ 和 $E_{\text{M}}$ 的极性都与整流状态时相反，**均为负值**。每个晶闸管导通 $2\pi/3$，故流过晶闸管的**电流有效值**为：
$$I_{\text{VT}} = \frac{1}{\sqrt{3}} I_{\text{d}}$$
- 在三相桥式电路中，每个周期内流经电源的线电流的导通角为 $4\pi/3$，是每个晶闸管导通角 $2\pi/3$ 的 2 倍，因此**变压器二次线电流的有效值**为：$$I_2 = \sqrt{2} I_{\text{VT}} = \sqrt{\frac{2}{3}} I_{\text{d}}$$
- **从交流电源送到直流侧负载的有功功率**为：
$$P_{\text{d}} = R_{\Sigma} I_{\text{d}}^2 + E_{\text{M}} I_{\text{d}}$$
- 当逆变工作时，由于 $E_{\text{M}}$ 为负值，故 $P_{\text{d}}$ 一般为负值，表示**功率由直流电源输送到交流电源**。
