- 前面分析整流电路时，  ，认为换相是瞬时完成的。
- 但实际上**变压器绕组总有漏感**，该漏感可用一个集中的电感 $L_B$ 表示，并将其**折算到变压器二次侧**。
- 由于电感对电流的变化起阻碍作用，使**电感电流不能突变**，因此**换相过程不能瞬间完成**，而是会持续一段时间。
- 图 3-18 为考虑变压器漏感时的**三相半波可控整流电路带电感负载**的电路及波形。![[图3-18 考虑变压器漏感时的三相半波可控整流带电感负载的电路及波形.png|center]]
- **假设负载中电感很大，负载电流为水平线。**
## 工作原理
1. 该电路在交流电源的一周期内有 **3 次晶闸管换相过程**，每次换相情况一样。
2. 以 **VT1 换相至 VT2** 的过程为例：
    - **1)** 在 $\omega t_1$ 时刻之前 VT1 导通，$\omega t_1$ 时刻触发 VT2，VT2 导通；
    - **2)** 因 a、b 两相均有漏感，故 $i_a$、$i_b$ 均不能突变，于是 **VT1 和 VT2 同时导通**，
		- 相当于将 a、b 两相短路，在两相组成的回路中产生**环流** $i_k$，$i_k = i_b$ 是逐渐增大的，而 $i_a = I_d - i_k$ 是逐渐减小的。
    - **3)** 当 $i_k$ 增大到等于 $I_d$ 时，$i_a = 0$，**VT1 关断**，换流过程结束。
# 一、整流输出电压
- 在上述换相过程中，**整流输出电压瞬时值**为：$$u_d = u_a + L_B \frac{\text{d}i_a}{\text{d}t} = u_b - L_B \frac{\text{d}i_b}{\text{d}t} = \frac{u_a + u_b}{2} \tag{3-1}$$
- 由式（3-1）可知，在换相过程中，整流电压 $u_d$ 为同时导通的两个晶闸管所对应的**两个相电压的平均值**。
# 二、换相压降
- 与不考虑变压器漏感时相比，每次换相 $u_d$ 波形均少了阴影标出的一块，导致 **$u_d$ 平均值降低**，降低的多少用 $\Delta U_d$ 表示，称为**换相压降**。$$\Delta U_d = \frac{1}{\frac{2\pi}{3}} \int_{\frac{\pi}{6}+\alpha}^{\frac{\pi}{6}+\alpha+\gamma} (u_b - u_d) \text{d}(\omega t) = \frac{3}{2\pi} \int_0^{I_d} \omega L_B \text{d}i_k = \frac{3}{2\pi} X_B I_d$$

# 三、换相重叠角
- 换相过程持续的时间，用电角度 $\gamma$ 表示，称为**换相重叠角**。$$\cos\alpha - \cos(\alpha + \gamma) = \frac{2X_B I_d}{\sqrt{6}U_2}$$
- $\gamma$ 随其他参数**变化的规律**：
	1. $I_d$ 越大，$\gamma$ 越大。
	2. $X_B$ 越大，$\gamma$ 越大。
	3. 当 $\alpha \le 90^\circ$ 时，$\alpha$ 越小，$\gamma$ 越大。
- **表 3-2 各种整流电路换相压降和换相重叠角的计算**

|**电路形式**|**单相全波**|**单相全控桥**|**三相半波**|**三相全控桥**|**m 脉波整流电路**|
|---|---|---|---|---|---|
|$\Delta U_d$|$\frac{X_B}{\pi}I_d$|$\frac{2X_B}{\pi}I_d$|$\frac{3X_B}{2\pi}I_d$|$\frac{3X_B}{\pi}I_d$|$\frac{mX_B}{2\pi}I_d$ ①|
|$\cos\alpha - \cos(\alpha + \gamma)$|$\frac{I_d X_B}{\sqrt{2}U_2}$|$\frac{2I_d X_B}{\sqrt{2}U_2}$|$\frac{2X_B I_d}{\sqrt{6}U_2}$|$\frac{2X_B I_d}{\sqrt{6}U_2}$|$\frac{I_d X_B}{\sqrt{2}U_2 \sin \frac{\pi}{m}}$ ②|

>[!note]
① 单相全控桥电路中，环流 $i_k$ 是从 $-I_d$ 变为 $I_d$。
> ② 三相桥等效为相电压等于 $\sqrt{3}U_2$ 的 6 脉波整流电路，故其 $m=6$，相电压按 $\sqrt{3}U_2$ 代入。
# 四、考虑变压器漏感对整流电路影响的一些结论
1. 出现**换相重叠角** $\gamma$，整流输出**电压平均值** $U_d$ **降低**。
2. 整流电路的**工作状态增多**。例如三相桥的工作状态由 6 种增加至 **12 种**：
    $$(\text{VT1}、\text{VT2}) \rightarrow (\text{VT1}、\text{VT2}、\text{VT3}) \rightarrow (\text{VT2}、\text{VT3}) \rightarrow (\text{VT2}、\text{VT3}、\text{VT4}) \rightarrow (\text{VT3}、\text{VT4}) \rightarrow (\text{VT3}、\text{VT4}、\text{VT5}) \rightarrow (\text{VT4}、\text{VT5}) \rightarrow (\text{VT4}、\text{VT5}、\text{VT6}) \rightarrow (\text{VT5}、\text{VT6}) \rightarrow (\text{VT5}、\text{VT6}、\text{VT1}) \rightarrow (\text{VT6}、\text{VT1}) \rightarrow (\text{VT6}、\text{VT1}、\text{VT2}) \rightarrow \cdots$$
    
3. 晶闸管的 $\frac{\text{d}i}{\text{d}t}$ **减小**，有利于晶闸管的**安全开通**，有时人为**串入进线电抗器**以抑制晶闸管的 $\frac{\text{d}i}{\text{d}t}$。
4. 换相时晶闸管**电压出现缺口**，产生正的 $\frac{\text{d}u}{\text{d}t}$，可能使晶闸管**误导通**，为此必须加**吸收电路**。
5. 换相使**电网电压出现缺口**，成为**干扰源**。
