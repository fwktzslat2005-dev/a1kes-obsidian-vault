- 单相整流电路中应用较多的是**单相桥式全控整流电路**。
# 一、带电阻负载的工作情况
- 图 3-4 为**带电阻负载的单相桥式全控整流电路及其波形**。![[图3-4 带电阻负载的单相桥式全控整流电路及波形.png|center]]

## 1. 工作原理
![[图3-4 带电阻负载的单相桥式全控整流电路及波形（工作原理）.png|center]]
- 在**单相桥式全控整流电路**中，
	- 晶闸管 $\text{VT1}$ 和 $\text{VT4}$ 组成**一对桥臂**， $\text{VT2}$ 和 $\text{VT3}$ 组成**另一对桥臂**。
		- 同时导通，同时关断
	1. 在 $u_2$ **正半周**，
		- 若 4 个晶闸管**均不导通**，
			- 负载电流 $i_d$ 为零，$u_d$ 也为零，
			- $\text{VT1}$ 和 $\text{VT4}$ **串联承受电压** $u_2$，设 $\text{VT1}$ 和 $\text{VT4}$ 的**漏电阻相等**，则各承受 $u_2$ 的一半。
	2. 若在**触发角** $\alpha$ 处给 $\text{VT1}$ 和 $\text{VT4}$ 加**触发脉冲**，
		- $\text{VT1}$ 和 $\text{VT4}$ **立即导通**，
		- 电流从电源 a 端经 $\text{VT1}$、$\text{R}$、$\text{VT4}$ 流回电源 b 端。
	3. 当 $u_2$ **过零**时，
		- 流经晶闸管的电流也降到零，$\text{VT1}$ 和 $\text{VT4}$ **关断**。
	4. 在 $u_2$ **负半周**，仍在**触发延迟角** $\alpha$ 处
		- 触发 $\text{VT2}$ 和 $\text{VT3}$，$\text{VT2}$ 和 $\text{VT3}$ **导通**，
		- 电流从电源 b 端流出，经 $\text{VT3}$、$\text{R}$、$\text{VT2}$ 流回电源 a 端。
	5. 到 $u_2$ **过零**时，
		- 电流又降为零，$\text{VT2}$ 和 $\text{VT3}$ **关断**。
## 2. 重要结论
![[图3-4 带电阻负载的单相桥式全控整流电路及波形（笔记）.png|center]]
1. 由于在交流电源的**正负半周都有整流输出电流流过负载**，故该电路为***全波整流***。
2. 在 $u_2$ 一个周期内，整流电压波形**脉动 2 次**（$m=2$），脉动次数多于半波整流电路，该电路属于**双脉波整流电路**。
3. 变压器**二次绕组中，正负两个半周电流方向相反且波形对称**，平均值为零，即**直流分量为零**，**不存在变压器直流磁化问题**，变压器绕组的**利用率也高**。
4. 晶闸管的**导通角**为 $\theta = \pi - \alpha$。
5.   晶闸管承受的**最大正向电压**为 $U_{\text{DM}} = \sqrt{2}U_2 / 2$，
	**最大反向电压**为 $U_{\text{RM}} = \sqrt{2}U_2$。
## 3. 基本数量关系
1. **直流侧输出电压平均值**为$$U_d = \frac{1}{\pi} \int_{\alpha}^{\pi} \sqrt{2}U_2 \sin\omega t \, \mathrm{d}(\omega t) = 0.9U_2 \frac{1 + \cos\alpha}{2}$$
	- $\alpha = 0^\circ$ 时，
		- **整流输出电压平均值为最大**，$U_d = U_{\text{d0}} = 0.9U_2$。
	- $\alpha = \pi$ 时，
		- $U_d = 0$；该电路中 $\text{VT}$ 的 $\alpha$ **移相范围**为 $0^\circ \sim 180^\circ$。
2. 向负载输出的**直流电流平均值**为$$I_d = \frac{U_d}{R} = \frac{0.9U_2}{R} \frac{1 + \cos\alpha}{2}$$
3. 流过**晶闸管电流的平均值**为$$I_{\text{dVT}} = \frac{1}{2} I_d$$
4. 流过**晶闸管电流的有效值**为(*不重要*)$$I_{\text{VT}} = \frac{U_2}{\sqrt{2}R} \sqrt{\frac{1}{2\pi} \sin 2\alpha + \frac{\pi - \alpha}{\pi}}$$
5. **变压器二次电流有效值** $I_2$ 与**输出直流电流有效值** $I$ 相等，为(*不重要*)
$$I_2 = I = \frac{U_2}{R} \sqrt{\frac{1}{2\pi} \sin 2\alpha + \frac{\pi - \alpha}{\pi}} = \sqrt{2}I_{\text{VT}}$$
6. 忽略变压器的损耗时，要求**变压器的容量**为 $S = U_2 I_2$。
# 二、带阻感负载时的工作情况
- 假设**负载电感很大**，负载电流 $i_d$ **连续**且波形**近似为一水平线**。
- 图3-5 **为带阻感负载的单相桥式全控整流电路及其波形**![[图3-5 带阻感负载的单相桥式全控整流电路及波形.png|center]]
## 1. 工作原理
![[图3-5 带阻感负载的单相桥式全控整流电路及波形（笔记）.png|center]]
1. 在 $u_2$ 的**正半周期**，
	- 触发角 $\alpha$ 处给晶闸管 $\text{VT1}$ 和 $\text{VT4}$ 加**触发脉冲**使其开通，$u_d = u_2$。
2. 当 $u_2$ **过零变负**时，
	- 由于**电感的作用**，晶闸管 $\text{VT1}$ 和 $\text{VT4}$ 中**仍流过电流 $i_d$，并不关断**。
3. 至 $\omega t = \pi + \alpha$，给 $\text{VT2}$ 和 $\text{VT3}$ 加**触发脉冲**，
	- 因 $\text{VT2}$ 和 $\text{VT3}$ 本已承受正电压，故**两管导通**。
	- $\text{VT2}$ 和 $\text{VT3}$ 导通后，$u_2$ 通过 $\text{VT2}$ 和 $\text{VT3}$ 分别向 $\text{VT1}$ 和 $\text{VT4}$ **施加反压**使这两个器件**关断**，流过 $\text{VT1}$ 和 $\text{VT4}$ 的**电流迅速转移**到 $\text{VT2}$ 和 $\text{VT3}$ 上。
## 2. 重要结论 1
1. **晶闸管的导通角**为 $\theta = 180^\circ$，与**触发角** $\alpha$ 无关；
	- $L$ 续流
2. $RL$ 时，$0^\circ \le \alpha \le 90^\circ$ ,
	- $\alpha = 90^\circ$ 时，正负半周面积相等$\Rightarrow S=0$
3. 晶闸管承受的**最大正反向电压**为$$U_{\text{DM}} = U_{\text{RM}} = \sqrt{2}U_2$$
## 3. 基本数量关系
1. **直流侧输出电压平均值**为$$U_d = \frac{1}{\pi} \int_{\alpha}^{\pi+\alpha} \sqrt{2}U_2 \sin\omega t \, \mathrm{d}(\omega t) = 0.9U_2 \cos\alpha$$
	- $\alpha = 0^\circ$ 时，**整流输出电压平均值为最大**，$U_d = U_{\text{d0}} = 0.9U_2$。
	- $\alpha = 90^\circ$ 时，$U_d = 0$，该电路中晶闸管触发角 $\alpha$ 的**移相范围**为 $0^\circ \sim 90^\circ$。
		- 除了[[3.1.1 单相半波可控整流电路 A类考点#2. 结论]]和[[3.1.2 单相桥式全控整流电路 A类考点#二、带阻感负载时的工作情况]]外，$\alpha$的**移相范围**都为 $0^\circ \sim 180^\circ$
2. 流过**晶闸管电流的平均值**为$$I_{\text{dVT}} = \frac{1}{2} I_d$$
3. 流过**晶闸管电流的有效值**为$$I_{\text{VT}} = \frac{1}{\sqrt{2}} I_d$$
4. 变压器二次电流 $i_2$ 的波形为正负各 $180^\circ$ 的**矩形波**，其相位由触发角 $\alpha$ 角决定，电流的**有效值**为$$I_2 = I_d$$
# 三、带反电动势负载时的工作情况
- 当负载为**蓄电池**、**直流电动机的电枢**（忽略其中的电感）等时，负载可看成是一个**直流电压源**，对于整流电路，它们就是**反电动势负载**。
- 图3-6 **为带反电动势—电阻负载的单相桥式全控整流电路及波形。**![[图3-6 带反电动势—电阻负载的单相桥式全控整流电路及波形.png|center]]
## 1. 反电动势—电阻负载
- ![[图3-6 带反电动势—电阻负载的单相桥式全控整流电路及波形（笔记）.png|center]]
- 只有 $|u_2| > E$ 时，才有晶闸管**承受正电压**，有**导通的可能**。
	1. $\alpha > \delta$：
		- 晶闸管**触发导通**之后，$u_d = u_2$，直至 $|u_2| = E$，$i_d$ **降到零**使得晶闸管**关断**，此后 $u_d = E$
		- 与电阻负载时相比，晶闸管提前了电角度 $\delta$ 停止导电，$\delta$ 称为**停止导电角**。$$\delta = \arcsin\left(\frac{E}{\sqrt{2}U_2}\right)$$
		- ### 重要结论 1
			- **晶闸管的导通角**为 $\theta = \pi - \alpha - \delta$。
			- 在触发角 $\alpha$ 相同时，**整流输出电压平均值**比电阻负载时大。
	2. $\alpha < \delta$：
		- **晶闸管承受负电压**，不可能导通。
		- 为了使晶闸管**可靠导通**，要求**触发脉冲**有足够的宽度，以使得当 $\omega t = \delta$ 时刻晶闸管开始承受**正电压**时，触发脉冲仍然存在。
		- 相当于**触发角被推迟**了 $\delta$。
		- ### 重要结论 2
			- 晶闸管的**导通角**为 $\theta = \pi - 2\delta$，与触发角无关。
			- **输出电压** $u_d$ **波形**与不控整流电路相同。
## 2. 直流电动机负载
- 如果出现**电流断续**，则电动机的**机械特性将很软**。
- 为了使负载电流连续，一般在主电路的直流输出侧串联一个**平波电抗器**，用来**减少电流的脉动**和**延长晶闸管导通的时间**。
