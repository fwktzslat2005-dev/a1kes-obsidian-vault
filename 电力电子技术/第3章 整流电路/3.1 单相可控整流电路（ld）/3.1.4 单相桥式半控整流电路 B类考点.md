# 电路分析
- 将**单相桥式全控整流电路**中的 $\text{VT2}$ 和 $\text{VT4}$ 换成 $\text{VD2}$ 和 $\text{VD4}$，即成为**单相桥式半控整流电路**。
- 半控电路与全控电路在**电阻负载**时的工作情况相同。
- 以下针对**电感负载**进行分析。
# 一、不带续流二极管

## 1. 正常时的工作原理
![[图3-8 单相桥式半控整流电路，不带续流二极管的阻感负载时电路及波形（工作原理）.png|center]]

- 每一个导电回路由 **1 个晶闸管和 1 个二极管**构成。
	1. 在 $u_2$ **正半周**，
		- 触发角 $\alpha$ 处触发 $\text{VT1}$，$u_2$ 经 $\text{VT1}$ 和 $\text{VD4}$ 向负载供电。
	2. $u_2$ **过零变负**时，
		- 因**电感作用**使电流连续，$\text{VT1}$ 继续导通，
		- 但因 $a$ 点电位低于 $b$ 点电位，电流是由 $\text{VT1}$ 和 $\text{VD2}$ **续流**，$u_d = 0$。
			- 不像全控桥那样会出现 $u_d$ 为负的情况。
	3. 在 $u_2$ **负半周**，
		- 触发角 $\alpha$ 处触发触发 $\text{VT3}$，
		- $\text{VT3}$ 向 $\text{VT1}$ 加反压使之关断，$u_2$ 经 $\text{VT3}$ 和 $\text{VD2}$ 向负载供电。
	4. $u_2$ **过零变正**时，
		- $\text{VD4}$ 导通，$\text{VD2}$ 关断。
		- $\text{VT3}$ 和 $\text{VD4}$ **续流**，$u_d$ 又为零。
## 2. 失控现象
![[图3-8 单相桥式半控整流电路，不带续流二极管的阻感负载时电路及波形（失控现象）.png|center]]
- 当触发角 $\alpha$ 突然增大至 $180^\circ$ 或**触发脉冲丢失**时，会发生一个晶闸管持续导通而两个二极管轮流导通的情况，这使 $u_d$ 成为**正弦半波**，即半周期 $u_d$ 为正弦，另外半周期 $u_d$ 为零，其平均值保持恒定，相当于**单相半波不可控整流电路**时的波形，称为**失控**。
# 二、带续流二极管

- 图 3-8 为**单相桥式半控整流电路，带续流二极管的阻感负载时电路及波形**。![[图3-8 单相桥式半控整流电路，带续流二极管的阻感负载时电路及波形（笔记+工作原理）.png|center]]
## 1. 重要结论
1. 有**续流二极管** $\text{VD}_\text{R}$ 时， 续流过程由 $\text{VD}_\text{R}$ 完成，**避免了失控的现象**。
2. 续流期间导电回路中**只有一个管压降**，少了一个管压降，**有利于降低损耗**。
