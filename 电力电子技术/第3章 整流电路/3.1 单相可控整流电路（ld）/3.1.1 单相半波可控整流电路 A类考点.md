# 一、带电阻负载的工作情况
- **电阻负载**的特点是**电压与电流成正比，两者波形相同**。
	- $\dot{I}_\text{d}=\dfrac{1}{R}\dot{U}_\text{d}$
- 图 3-1 所示为带电阻负载时的**单相半波可控整流电路及波形**。![[图3-1 带电阻负载时的单相半波可控整流电路及波形.jpg|center]]
## 1. 电路结构
- 如图 3-1 所示的电路原理图中，
- $T$ 为**变压器**，起**变换电压和隔离**的作用，
	- 其一次侧和二次侧电压的*瞬时值*分别用 $u_1$、 $u_2$ 来表示，
	- *有效值*分别用 $U_1$、 $U_2$ 来表示，
		- 通常 $U_2$ 的大小根据需要的直流输出电压 $u_d$ 的平均值 $U_d$ 确定；
		- $\dfrac{U_1}{U_2}=\dfrac{N_1}{N_2}$
		- $u_1=\sqrt{2}U_1\sin{\omega t}$ ,$u_2=\sqrt{2}U_2\sin{\omega t}$
- $VT$ 为**晶闸管**，在分析整流电路时，认为**晶闸管是理想的**；
- $R$ 为**电阻**，其**电压瞬时值**为 $u_d$，**电流瞬时值**为 $i_d$。
## 2. 工作原理
- **单相半波可控整流电路带电阻负载**时的**工作波形**如图 3-1 所示，$i_d$ 的波形与 $u_d$ 波形相同。
- **晶闸管 $VT$ 处于断态**：
	- 电路中**无电流**，直流侧**输出电压瞬时值** $u_d$ 和直流侧**输出电流瞬时值** $i_d$ 均为零，变压器二次侧绕组**电压瞬时值** $u_2$ 全部施加于晶闸管 $VT$ 两端。
		- $VT$反压 $or$ $I_\text{VT}=0$
- **晶闸管 $VT$ 处于通态**：
	1. 如在 $u_2$ **正半周** $VT$ 承受**正向阳极电压**期间的 $\omega t_1$ 时刻，
	2. 给 $VT$ 门极加**触发脉冲**$I_\text{g}$，
		- 则 $VT$ **开通**。
		- 正向阳极电压: $U_\text{A}>U_\text{K}$，$A\rightarrow +，B\rightarrow -$
	- 忽略晶闸管**通态电压**，则 $u_d = u_2$。至 $\omega t = \pi$，即 $u_2$ 降为零时，电路中**电流亦降至零**，$VT$ **关断**。
	
- *时间表*：
	- $0\sim \omega t$:$VT$ 正压，无$I_\text{g}$，$VT$**断态**
	- $\omega t\sim \pi$:$VT$ 正压，有$I_\text{g}$,$VT$**导通**
	- $\pi \sim 2\pi$:$VT$ 反压，$VT$**断态**
- 其余周期重复上述过程。
## 3. 结论 1
1. 改变**触发时刻**，$u_d$ 和 $i_d$ 波形随之改变，直流输出电压 $u_d$ 为**极性不变但瞬时值变化的脉动直流**。
	- $u_d$ 的波形只在 $u_2$ 正半周内出现，故**称“半波”整流**。
	- 加之电路中采用了可控器件晶闸管，且交流输入为单相，故该电路称为**单相半波可控整流电路**。
2. 整流电压 $u_d$ 波形在一个电源周期中**只脉动 1 次**，故该电路为**单脉波整流电路**。
3. 变压器二次侧电流为**单向**，故该电路为**单拍电路**。
## 4. 结论 2
1. 晶闸管的**导通角** $\theta = \pi - \alpha$。
2. 闸管承受的**最大正、反向电压**为 $U_{\text{DM}} = U_{\text{RM}} = \sqrt{2}U_2$。
3. 直流侧**输出电压平均值**为$$U_d = \frac{1}{2\pi} \int_{\alpha}^{\pi} \sqrt{2}U_2 \sin\omega t \, \mathrm{d}(\omega t) = 0.45U_2 \frac{1 + \cos\alpha}{2}$$
	- $U_d$ 是**触发角** $\alpha$ 的函数，通过调节 $\alpha$ 即可控制 $U_d$ 的大小。
	- $\alpha = 0°$ 时，$U_d$ 为**最大**，$U_{\text{dmax}} = U_{\text{d0}} = 0.45U_2$。
	- 随着 $\alpha$ 增大，$U_d$ 减小；
	- $\alpha = \pi$ 时，$U_d = 0$；
	- 该电路中触发角 $\alpha$ 的**移相范围**为 0° ～ 180°。
# 二、带阻感负载的工作情况
- 实际生产中，更常见的负载为**阻感负载**，
- 负载中的**电感**对电流的变化有**抑制作用**，从而使流过电感中的**电流不能突变**。
## 1. 工作原理
- 图 3-2 为**带阻感负载的单相半波可控整流电路及其波形**。![[图3-2 带阻感负载的单相半波可控整流电路及波形.jpg|center]]
- **晶闸管 VT 处于断态**：
	- 电路中电流 $i_d = 0$，负载两端电压 $u_d = 0$，电源电压 $u_2$ 全部加在 **VT 两端**。
- **晶闸管 VT 处于通态**：
	- 在 $\omega t_1$ 时刻，即**触发角** $\alpha$ 处，
		- 触发 VT 使其开通，$u_2$ 加于负载两端，
		- 因**电感 $L$ 的存在**使 $i_d$ **不能突变**，$i_d$ 从 0 开始增加，
		- 同时 $L$ 的**感应电动势**试图阻止 $i_d$ 增加。
		- 这时，交流电源
			- 一方面供给**电阻 $R$ 消耗的能量**，
			- 另一方面供给**电感 $L$ 吸收的磁场能量**。
	- 到 $u_2$ 由正变负的**过零点处**，
		- 过零点后 $u_2$ 变为负值，
		- 但因为**电感 $L$ 的作用使 $i_d$ 不能突变**，因此 VT **仍处于通态**。
	- 此后，$L$ 中储存的能量逐渐释放，
		- 一方面供给电阻消耗的能量，
		- 另一方面供给**变压器二次绕组**吸收的能量，从而**维持 $i_d$ 流动**。
	- 至 $\omega t_2$ 时刻，
		- **电感能量释放完毕**，$i_d$ 降至零，VT **关断**并立即承受反压。
- *时间表*：
	- $0\sim \omega t$:$VT$ 正压，无$I_\text{g}$，$VT$**断态**
	- $\omega t_1\sim \pi$:$VT$ 正压，有$I_\text{g}$，$VT$**导通**
	- $\pi\sim \omega t_2$:$VT$ 负压，但有$L$ 续流，$VT$**导通**
	- $\omega t_2\sim 2\pi$:$VT$ 负压，$L$ 续流完毕，$VT$**断态**
- 直流侧**输出电压平均值**为$$U_d = \frac{1}{2\pi} \int_{\alpha}^{\pi} \sqrt{2}U_2 \sin\omega t \, \mathrm{d}(\omega t) + \frac{1}{2\pi} \int_{\pi}^{\omega t_2} \sqrt{2}U_2 \sin\omega t \, \mathrm{d}(\omega t)$$
## 2. 结论
1. 由于**电感的存在**延迟了 VT 的关断时刻，使 $u_d$ 波形**出现负的部分**，
	- 与带电阻负载时相比，其**平均值 $U_d$ 下降**。
2. 当负载**阻抗角** $\varphi$ 或**触发角** $\alpha$ 不同时，晶闸管的**导通角** $\theta$ 也不同。
    1. 若 $\varphi$ 为定值，
	    - $\alpha$ 角越大，在 $u_2$ 正半周电感 $L$ **储能越少**，维持导电的能力就越弱，**$\theta$ 越小**。
    2. 若 $\alpha$ 为定值，
	    - $\varphi$ 越大，则 $L$ **储能越多**，**$\theta$ 越大**。
	    - 且 $\varphi$ 越大，
		    - 在 $u_2$ 负半周 $L$ 维持晶闸管导通的时间就越接近晶闸管在 $u_2$ 正半周导通的时间，
		    - $u_d$ 中**负的部分越接近正的部分**，**平均值 $U_d$ 越接近零**，输出的直流电流平均值也越小。
# 三、带续流二极管的工作情况
- 为解决上述矛盾，在整流电路的负载两端并联一个**二极管 $\text{VD}_\text{R}$**，如图 3-3 所示。![[图3-3 单相半波带阻感负载有续流二极管的电路及波形.jpg|center]]
## 1. 工作原理
1. 与没有续流二极管时的情况相比，在 $u_2$ **正半周**时两者工作情况相同。
2. 当 $u_2$ **过零变负**时，$\text{VD}_\text{R}$ **导通**，$u_d$ 为零。
	- 此时，$u_2$ 通过 $\text{VD}_\text{R}$ 向 $\text{VT}$ 施加**反压**使其关断，$L$ 储存的能量通过 $\text{VD}_\text{R}$ **续流**。
- *时间表*：
	- $0\sim \omega t$:$VT$ 正压，无$I_\text{g}$，$VT$**断态**
	- $\omega t_1\sim \pi$:$VT$ 正压，有$I_\text{g}$，$VT$**导通**
	- $\pi \sim 2\pi$:$VT$**断态**，$\text{VD}_\text{R}$ **导通**续流
## 2. 重要结论 1
1. 忽略二极管的通态电压，则在**续流期间** $u_d$ **为零**，与电阻负载时基本相同，其波形中**不再出现负的部分**。
2. 但与电阻负载时相比，$i_d$ 的波形不同。
	- 若 $L$ **足够大**，$i_d$ **连续**，且 $i_d$ 波形**接近一条水平线**。
3. 晶闸管**触发角**$\alpha$的移相范围为 **0 ~ 180°**；
4.  晶闸管的**导通角**为 $\theta = \pi - \alpha$；
	**续流二极管** $\text{VD}_\text{R}$ 的导通角为 $\theta = \pi + \alpha$；
5.  晶闸管 $\text{VT}$ 承受的**最大正反向电压**均为 $U_{\text{DM}} = U_{\text{RM}} = \sqrt{2}U_2$；
	续流二极管 $\text{VD}_\text{R}$ 承受的**最大反向电压**为 $U_{\text{RM}} = \sqrt{2}U_2$。
## 3. 基本数量关系
1. **晶闸管电流**的**平均值**及**有效值**分别为
$$I_{\text{dVT}} = \frac{\pi - \alpha}{2\pi} I_d$$
$$I_{\text{VT}} = \sqrt{\frac{\pi - \alpha}{2\pi}} I_d$$
2. **续流二极管电流**的**平均值**及**有效值**分别为
$$I_{\text{dVD}_\text{R}} = \frac{\pi + \alpha}{2\pi} I_d$$
$$I_{\text{VD}_\text{R}} = \sqrt{\frac{\pi + \alpha}{2\pi}} I_d$$

## 4. 重要结论 2
- **单相半波可控整流电路**的特点：
	1. **简单**；
	2. **输出脉动大**；
	3. 变压器二次电流中**含直流分量**，造成变压器铁心**直流磁化**。
		- 为使变压器铁心不饱和，需**增大铁心截面积**，增大了设备的容量。
		- *半波整流电路*，**变压器二次侧**存在**直流磁化问题**
	4. 实际上**很少应用**此种电路。
