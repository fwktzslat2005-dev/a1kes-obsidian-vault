- 当负载容量较大，或要求直流电压脉动较小、容易滤波时，应采用**三相整流电路**，其交流侧由三相电源供电。
- 三相可控整流电路中：
	- 最基本的是**三相半波可控整流**，
	- 应用最广泛的是**三相桥式全控整流**、**双反星型可控整流**及**十二脉波可控整流电路**等。
