## 非正弦电路
- 公用电网中，通常**电压的波形畸变很小**，而**电流波形的畸变可能很大**。
	- 因此，不考虑电压畸变，研究电压波形为正弦波、电流波形为非正弦波的情况有很大的实际意义。
- 设正弦电压有效值为 $U$，畸变电流有效值为 $I$，**基波电流有效值**及与电压的**相位差**分别为 $I_1$ 和 $\phi_1$。
	- 这时**有功功率**为：$$P = UI_1 \cos\phi_1$$
	- **功率因数**为$$\lambda = \frac{P}{S} = \frac{U I_1 \cos\phi_1}{U I} = \frac{I_1}{I} \cos\phi_1 = \nu \cos\phi_1$$
	- 式中，
		- $\nu$ 为**基波电流有效值和总电流有效值之比**，$\nu = I_1 / I$，称为**基波因数**；
		- $\cos\phi_1$ 称为**位移因数**或**基波功率因数**。
		- 可见，**功率因数**由**基波电流相移**和**电流波形畸变**这两个因素共同决定。
