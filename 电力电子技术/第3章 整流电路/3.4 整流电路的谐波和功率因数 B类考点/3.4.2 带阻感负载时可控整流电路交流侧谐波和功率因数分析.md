# 一、单相桥式全控整流电路
- 带阻感负载的单相桥式整流电路，直流电感 $L$ 为**足够大**，忽略换相过程和电流脉动时，变压器二次电流波形近似为**理想方波**，如图 3-19 所示。![[图3-19 带大阻感负载单相桥式全控整流电路变压器二次电流波形.png|center|514]]
- 将变压器二次侧绕组电流波形分解为**傅里叶级数**，可得：$$i_2 = \frac{4}{\pi} I_d \left[ \sin\omega t + \frac{1}{3}\sin3\omega t + \frac{1}{5}\sin5\omega t + \frac{1}{7}\sin7\omega t + \cdots \right]$$$$= \frac{4}{\pi} I_d \sum_{n=1,3,5,\cdots} \frac{1}{n}\sin n\omega t = \sum_{n=1,3,5,\cdots} \sqrt{2}I_n \sin n\omega t$$
	- 其中，**基波和各次谐波有效值**为：

$$I_n = \frac{2\sqrt{2}I_d}{n\pi}, \quad n = 1,3,5,\cdots$$
## 2. 结论
- 除基波外，变压器二次侧绕组电流中**仅含奇次谐波**，各次谐波有效值与谐波次数**成反比**，且与基波有效值的比值为**谐波次数的倒数**。
- **基波电流有效值**为：$$I_1 = \frac{2\sqrt{2}I_d}{\pi} \approx 0.9I_d$$
- **基波因数**为：$$ \nu = \frac{I_1}{I} = \frac{2\sqrt{2}}{\pi} \approx 0.9$$
- 基波电流与（基波）电压的相位差就等于**控制角** $\alpha$，故**位移因数**为：$$\lambda_1 = \cos\phi_1 = \cos\alpha$$
- 因此，**功率因数**为：$$\lambda = \nu \lambda_1 \approx 0.9\cos\alpha$$
# 二、三相桥式全控整流电路
- 阻感负载的三相桥式整流电路，交流侧电抗为零，直流电感 $L$ 为**足够大**。
- 以 $\alpha = 30^\circ$ 为例，交流侧电压和电流波形如图 3-20 所示。![[图3-20 带大阻感负载三相桥式全控整流电路变压器二次电流波形.png|center]]
- 忽略换相过程和电流脉动，电流为正负半周各 $120^\circ$ 的**方波**，三相电流波形相同，且依次相差 $120^\circ$。
- 将变压器二次侧绕组电流波形分解为**傅里叶级数**，以 a 相电流为例，
	- 将电流负、正两半周的中点作为**时间零点**，则有$$i_a = \frac{2\sqrt{3}}{\pi} I_d \left[ \sin\omega t - \frac{1}{5}\sin5\omega t - \frac{1}{7}\sin7\omega t + \frac{1}{11}\sin11\omega t + \frac{1}{13}\sin13\omega t - \cdots \right]$$$$= \frac{2\sqrt{3}}{\pi} I_d \sin\omega t + \frac{2\sqrt{3}}{\pi} I_d \sum_{n=6k\pm1} (-1)^k \frac{1}{n}\sin n\omega t = \sqrt{2}I_1 \sin\omega t + \sum_{n=6k\pm1} (-1)^k \sqrt{2}I_n \sin n\omega t$$
	- 其中，**基波和各次谐波有效值**为：$$\begin{cases} I_1 = \frac{\sqrt{6}}{\pi} I_d \\ I_n = \frac{\sqrt{6}}{n\pi} I_d \end{cases} \quad n = 6k \pm 1, \; k = 1,2,3,\cdots$$
## 1. 结论
- 除基波外，变压器二次侧绕组电流中**仅含 $6k \pm 1$（$k$ 为正整数）次谐波**，各次谐波有效值与谐波次数**成反比**，且与基波有效值的比值为**谐波次数的倒数**。
- **基波因数**为：$$\nu = \frac{I_1}{I} = \frac{3}{\pi} \approx 0.955$$
- 基波电流与（基波）电压的相位差就等于**触发角** $\alpha$，故**位移因数**为：$$\lambda_1 = \cos\phi_1 = \cos\alpha$$
- 因此，**功率因数**为：$$\lambda = \nu \lambda_1 \approx 0.955\cos\alpha$$
