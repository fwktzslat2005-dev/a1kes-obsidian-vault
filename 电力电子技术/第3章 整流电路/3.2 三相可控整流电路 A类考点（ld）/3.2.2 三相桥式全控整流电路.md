- 习惯上希望晶闸管按从 1～6 的顺序导通，为此将晶闸管按图示的顺序编号，
	- 即**共阴极组**中与 a、b、c 三相电源相接的三个晶闸管分别为 $VT_1$、$VT_3$、$VT_5$，
	- **共阳极组**中与 a、b、c 三相电源相接的三个晶闸管分别为 $VT_4$、$VT_6$、$VT_2$。

## 1. $\alpha = 0^\circ$ 时
- 波形如图 3-13 (a) 所示。![[图3-13 三相桥式全控整流电路带电阻负载α=0°和α=30°时各参数波形（a）（笔记）.jpg.png|center]]
### 1）工作原理
![[图3-13 三相桥式全控整流电路带电阻负载α=0°和α=30°时各参数波形（a）（工作原理）.jpg.png|center]]
1. 
	- 对于共阴极组的 3 个晶闸管，**阳极所接交流相电压最高**的一个导通；
	- 而对于共阳极组的 3 个晶闸管，则是**阴极所接交流相电压最低**的一个导通。
	- 任意时刻，共阴极组和共阳极组中**各有一个晶闸管处于导通状态**，施加于负载上的电压为对应的**线电压**。
2. 
	- 各晶闸管均在**自然换相点**处换相，
	- 各个晶闸管都按相同的规律依次触发导通并关断前一个已导通的同组的晶闸管。
### 2）结论
1. 
	- 整流输出电压 $u_{\text{d}}$ 波形为**线电压在正半周的包络线**；
	- 在一个电源周期内，$u_{\text{d}}$ 的波形为 **6 段线电压拼接而成**；
	- 各晶闸管的**导通角均为 $120^\circ$**，**负载电流连续**。
2. 晶闸管承受电压的波形与三相半波时相同，晶闸管承受最大正、反向电压的关系也一样。
## 2. $\alpha = 30^\circ$ 时
- 各参数波形如图 3-13 (b) 所示。![[图3-13 三相桥式全控整流电路带电阻负载α=0°和α=30°时各参数波形（b）（笔记）.jpg.png|center]]

### 1）结论
1. 与 $\alpha = 0^\circ$ 的情况相比，一周期中 $u_{\text{d}}$ 波形仍由**六段线电压构成**，每一段导通晶闸管的编号等仍符合表 3-1 的规律。
	- 区别在于晶闸管起始导通时刻**推迟了 $30^\circ$**，组成 $u_{\text{d}}$ 的每一段线电压因此**推迟 $30^\circ$**；
	- $u_{\text{d}}$ 的**平均值降低**。
2. 各相（或各晶闸管）仍然**导电 $120^\circ$**。
### 2）三相桥式全控整流电路的一些特点如下
1. 需**两个晶闸管同时导通**才能形成向负载供电的回路，
	- 其中一个晶闸管是共阴极组的，
	- 一个是共阳极组的，
	- 且**不能为同一相**的晶闸管。
2. **对触发脉冲的要求**：
	- 六个晶闸管的脉冲按 $VT_1$—$VT_2$—$VT_3$—$VT_4$—$VT_5$—$VT_6$ 的顺序，相位依次差 $60^\circ$；
	- **共阴极组** $VT_1$、$VT_3$、$VT_5$ 的脉冲依次差 $120^\circ$，
	- **共阳极组** $VT_4$、$VT_6$、$VT_2$ 也依次差 $120^\circ$；
	- **同一相的上下两个桥臂**，即 $VT_1$ 与 $VT_4$，$VT_3$ 与 $VT_6$，$VT_5$ 与 $VT_2$，脉冲相差 $180^\circ$。
3. **整流输出电压** $u_{\text{d}}$ 一周期脉动六次，每次脉动的波形都一样，
	- 故该电路为**六脉波整流电路**，**脉动频率**为 $50 \times 6 = 300\text{Hz}$，比三相半波时大 1 倍。
4. 由于三相桥式全控整流电路每相上、下桥臂各有一个晶闸管，变压器二次侧绕组中均可在正、反两个方向上流过电流。
	- 这样，变压器绕组**电流平均值为零**，**无直流磁化问题**。
5. 在整流电路合闸启动过程中或电流断续时，为确保电路的正常工作，需保证**同时导通的两个晶闸管均有脉冲**。
	- 为此，可采用两种方法：![[图3-14 三相桥式全控整流电路，电阻负载，α=60°及α=90°时波形（单双宽脉波）.jpg|center]]
		- 一种方法是，使脉冲宽度大于 $60^\circ$（一般取 $80^\circ \sim 100^\circ$），称为**宽脉冲触发**；
		- 另一种方法是，在触发某个晶闸管的同时，给前一个晶闸管**补发脉冲**，即用两个窄脉冲代替宽脉冲，
			- 两个窄脉冲的前沿相差 $60^\circ$，脉宽一般为 $20^\circ \sim 30^\circ$，称为**双脉冲触发**。常用的是**双脉冲触发**。
## 3. $\alpha = 60^\circ$ 时
- 各参数波形如图 3-14 (a) 所示。![[图3-14 三相桥式全控整流电路，电阻负载，α=60°及α=90°时波形.jpg|center]]![[图3-14 三相桥式全控整流电路，电阻负载，α=60°时波形（笔记）.jpg.png|center]]
### 1）结论
1. 电路工作情况仍可对照表 3-1 分析。
	- $u_{\text{d}}$ 波形中每段线电压的波形继续向后移，$u_{\text{d}}$ **平均值继续降低**。
	- $\alpha = 60^\circ$ 时 $u_{\text{d}}$ **出现了为零的点**，负载电流处于**连续和断续的临界状态**。
2. 各相（或各晶闸管）仍然**导电 $120^\circ$**。
3. 在一个电源周期内，$u_{\text{VT}}$ 波形仍是由**一段管压降和两段线电压**组成，且各占 $1/3$。
4. 欲使负载电流连续时，触发角 $\alpha$ 的**移相范围**为 $0^\circ \le \alpha < 60^\circ$。
## 4. $\alpha > 60^\circ$ 时
- 例如 $\alpha = 90^\circ$ 时，各参数波形如图 3-14 (b) 所示。![[图3-14 三相桥式全控整流电路，电阻负载，α=90°时波形（笔记）.jpg.png|center]]
### 1）结论
1. $u_{\text{d}}$ 波形每 $60^\circ$ 中有 $30^\circ$ 为零（**负载电流断续**），这是因为电阻负载时 $i_{\text{d}}$ 波形与 $u_{\text{d}}$ 波形一致，一旦 $u_{\text{d}}$ 降至零，$i_{\text{d}}$ 也降至零。
	- 流过晶闸管的电流即降至零，晶闸管关断，输出整流电压 $u_{\text{d}}$ 为零。因此，$u_{\text{d}}$ 波形不能出现负值。
2. 如果 $\alpha$ 角继续增大至 $120^\circ$，整流输出电压 $u_{\text{d}}$ 波形将全为零，其平均值 $U_{\text{d}}$ 也为零，
	- 可见带电阻负载时三相桥式全控整流电路，$\alpha$ 角的**移相范围**是 $0^\circ \sim 120^\circ$。
		- $R$：连续$0^\circ \sim 60^\circ$，断续$60^\circ \sim 120^\circ$
3. 晶闸管的**导通角**为：$$\theta = 2 \times (120^\circ - \alpha)$$
# 二、阻感负载
- 三相桥式全控整流电路大多用于向**阻感负载**和**反电动势阻感负载**供电（即用于**直流电动机传动**），如图 3-15 所示。![[图3-15 三相桥式全控整流电路带阻感负载时的电路原理图.png|center]]
## 1. $\alpha \le 60^\circ$ 时
- 图 3-16 分别给出了三相桥式全控整流电路带阻感负载 $\alpha = 0^\circ$ 和 $\alpha = 30^\circ$ 时的波形。![[图3-16 三相桥式全控整流电路带阻感负载α=0°及α=30°时波形.png|center]]
### 1）结论
1. 电路的工作情况与带电阻负载时十分相似，
	- 各晶闸管的**通断情况**、输出整流电压 $u_{\text{d}}$ 的波形、晶闸管承受电压 $u_{\text{VT}}$ 的波形等都一样。
2. 区别在于由于负载不同，
	- 同样的整流输出电压加到负载上，得到的**负载电流 $i_{\text{d}}$ 波形不同**：
		- 电阻负载时 $i_{\text{d}}$ 波形与 $u_{\text{d}}$ 波形形状一样；
		- 而阻感负载时，由于**电感的作用**，使得负载电流波形变得平直，
			- 当电感足够大的时候，负载电流的波形可近似为**一条水平线**。
		- 在晶闸管的导通段，$i_{\text{VT}}$ 波形由**负载电流 $i_{\text{d}}$ 波形决定**。
## 2. $\alpha > 60^\circ$ 时
- 图 3-17 给出了 $\alpha = 90^\circ$ 时的波形。![[图3-17 三相桥式全控整流电路带阻感负载，α=90°时波形.png|center]]![[图3-17 三相桥式全控整流电路带阻感负载，α=90°时波形（笔记）.png|center]]

### 1）结论
1. 当 $\alpha > 60^\circ$ 时，**阻感负载**时的工作情况与**电阻负载**时不同，
	- 电阻负载时 $u_{\text{d}}$ 波形不会出现负的部分；
	- 而阻感负载时，由于**电感 $L$ 的作用**，$u_{\text{d}}$ 波形会**出现负的部分**。
2. 若电感 $L$ 值足够大，$u_{\text{d}}$ 中**正负面积将基本相等**，$u_{\text{d}}$ **平均值近似为零**。
	- 这表明，带阻感负载时，三相桥式全控整流电路的 $\alpha$ 角**移相范围**为 $0^\circ \sim 90^\circ$。
3. 整个移相范围内，晶闸管的**导通角均为 $120^\circ$**。
### 2）基本数量关系
1. 当**整流输出电压连续**时（即**带阻感负载**时，或**带电阻负载** $\alpha \le 60^\circ$ 时）的**平均值**为：$$U_{\text{d}} = 2.34 U_2 \cos \alpha$$
	- 连续：
		- $R$：$0^\circ \sim 60^\circ$
		- $L$：$0^\circ \sim 90^\circ$
	- 当 $\alpha = 0^\circ$ 时，$U_{\text{d}}$ 最大，为 $U_{\text{dmax}} = U_{\text{d0}} = 2.34 U_2$。
	- **带电阻负载**且 $\alpha > 60^\circ$ 时，**整流电压平均值**为：$$U_{\text{d}} = \frac{3}{\pi} \int_{\frac{\pi}{3} + \alpha}^{\pi} \sqrt{6} U_2 \sin \omega t \, \text{d}(\omega t) = 2.34 U_2 \left[ 1 + \cos \left( \frac{\pi}{3} + \alpha \right) \right]$$
		- 断续：$R$：$\rightarrow$ $60^\circ \sim 120^\circ$
2. **输出电流平均值**：$$I_{\text{d}} = \frac{U_{\text{d}}}{R}$$
3. **晶闸管电流的平均值**：$$I_{\text{dVT}} = \frac{I_{\text{d}}}{3}$$
4. **带阻感负载**（$L$ 值很大）时，晶闸管电流的**有效值**为：$$I_{\text{VT}} = \frac{I_{\text{d}}}{\sqrt{3}}$$
5. **带阻感负载**（$L$ 值很大）时，**变压器二次侧电流的有效值**为：$$I_2 = \sqrt{\frac{1}{2\pi} \left( I_{\text{d}}^2 \times \frac{2\pi}{3} + (-I_{\text{d}})^2 \times \frac{2\pi}{3} \right)} = \sqrt{\frac{2}{3}} I_{\text{d}}$$
6. **带电阻负载**时，晶闸管承受的**最大反向电压**为：$$U_{\text{RM}} = \sqrt{6} U_2$$
7. **带阻感负载**（$L$ 值很大）时，晶闸管承受的**最大正反向电压**分别为：$$U_{\text{DM}} = U_{\text{RM}} = \sqrt{6} U_2$$
8. 三相桥式全控整流电路接**反电动势阻感负载**时，在负载电感足够大足以使**负载电流连续**的情况下，
	- 电路工作情况与电感性负载时相似，电路中各处电压、电流波形均相同，
	- 仅在计算 $I_{\text{d}}$ 时有所不同，接反电动势阻感负载时的 $I_{\text{d}}$ 为：$$I_{\text{d}} = \frac{U_{\text{d}} - E}{R}$$
