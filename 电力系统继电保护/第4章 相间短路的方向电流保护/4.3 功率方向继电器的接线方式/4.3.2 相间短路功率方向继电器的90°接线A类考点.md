# 一、正方向发生三相短路

- **正方向**发生**三相短路**时的**相量图**如图 4-6 所示。图 4-6 中：![[图4-6 正方向发生三相短路时的电压电流相量图.png|center|310]]
	- $\dot{U}_A, \dot{U}_B, \dot{U}_C$ 表示保护安装地点**母线**的**相电压**；
	- $\dot{I}_A, \dot{I}_B, \dot{I}_C$ 为通过保护的**三相短路电流**；
	- **电流滞后电压**的角度为**线路阻抗角** $\phi_k$。
- 由于**三相对称**，3 个**方向继电器**工作情况完全一样，因此可只取 **A 相继电器**来分析。
- 由图 4-6 可见，接入继电器的电流 $\dot{I}_{KA} = \dot{I}_A$，电压 $\dot{U}_{KA} = \dot{U}_{BC}$，**电压超前电流**的角度为：
$$\phi_A = \phi_k - 90^\circ$$
- 则**相继电器**的**动作条件**为：
$$U_{BC} I_A \cos(\phi_k - 90^\circ + \alpha) > 0$$
- 为使继电器工作在**最灵敏状态**下，应使 $\cos(\phi_k - 90^\circ + \alpha) = 1$，即要求：
$$\phi_k + \alpha = 90^\circ$$
- 一般情况下，当不考虑**线路分布电容**，电力系统中任何电缆或架空线路的**阻抗角**（包括含有**过渡电阻**短路的情况）都位于 $0^\circ \le \phi_k \le 90^\circ$。为使**方向继电器**在任何 $\phi_k$ 情况下都能动作，就必须要求 $U_{BC} I_A \cos(\phi_k - 90^\circ + \alpha) > 0$ 始终成立，即要求：
$$-90^\circ \le \phi_k - 90^\circ + \alpha \le 90^\circ$$
- 为此需要选择一个合适的**内角**才能满足要求：
	- 当 $\phi_k = 0^\circ$ 时，$0^\circ \le \alpha \le 180^\circ$；
	- 当 $\phi_k = 90^\circ$ 时，$-90^\circ \le \alpha \le 90^\circ$。
- 为了同时满足以上两个条件，使**方向继电器**在任何情况下均能动作，则对于**三相短路**时，应选择：
$$0^\circ \le \alpha \le 90^\circ$$
# 二、正方向两相短路
- 图 4-7 所示为**两相短路**的情况、以 **BC 两相短路**为例，存在两种极限情况：一种是**短路点位于保护安装地点附近**；另一种是**短路点远离保护安装地点**。![[图4-7 正方向发生两相短路时的电路图.png|center|325]]
## 1.短路点位于保护安装地点附近
- **短路阻抗** $Z_k$（保护安装处到短路点间的阻抗）很小，极限情况取 $Z_k = 0$。此时，**短路电流** $\dot{I}_B$ 由**电动势** $\dot{E}_{BC}$ 产生，$\dot{I}_B$ 滞后 $\dot{E}_{BC}$ 的角度为 $\phi_k$，电流 $\dot{I}_C = -\dot{I}_B$。设**系统阻抗** $Z_s$ 很小，短路点的电压为**电动势** $\dot{E}_{BC}$ 的中点，电压为：
$$\begin{aligned} \dot{U}_{KBC} &= 0 \\ \dot{U}_A &= \dot{U}_{KA} = \dot{E}_A \\ \dot{U}_B &= \dot{U}_{KB} = -\frac{1}{2} \dot{E}_A \\ \dot{U}_C &= \dot{U}_{KC} = -\frac{1}{2} \dot{E}_A \end{aligned}$$
- **相量图**如图 4-8 所示。![[图4-8 正方向发生两相短路时的电压电流相量图.png|center]]
- 此时，对 **A 相继电器**而言，当忽略**负荷电流**时，$I_A = 0$，因此**继电器不动**。
- 对于 **B 相继电器**，所加的电流、电压为 $\dot{I}_{KB} = \dot{I}_B$，$\dot{U}_{KB} = \dot{U}_{CA}$，**电压超前电流**的角度为 $\phi_B = -(90^\circ - \phi_k) = \phi_k - 90^\circ$，则**动作条件**为：
$$U_{CA} I_B \cos(\phi_k - 90^\circ + \alpha) > 0$$
- 同理，对于 **C 相继电器**，**动作条件**为：
$$U_{AB} I_C \cos(\phi_k - 90^\circ + \alpha) > 0$$
- 因此，为了在 $0^\circ \le \phi_k \le 90^\circ$ 时使 **B、C 两相**的继电器能**动作**，需要选择 $0^\circ \le \alpha \le 90^\circ$。因此，对于**近保护安装处两相短路**，应选择：
$$0^\circ \le \alpha \le 90^\circ$$

## 2.短路点远离保护安装地点
- 且系统容量很大，$Z_s$ 很小，此时 $Z_k \gg Z_s$。极限情况下取 $Z_s = 0$，则**母线电压**几乎等于**电动势**。电流 $\dot{I}_B$ 由**电动势** $\dot{E}_{BC}$ 产生，并滞后 $\dot{E}_{BC}$ 的一个角度 $\phi_k$。保护安装点的电压：
$$\begin{aligned} \dot{U}_A &= \dot{E}_A \\ \dot{U}_B &= \dot{U}_{KB} + \dot{I}_B Z_k = \dot{E}_B \\ \dot{U}_C &= \dot{U}_{KC} + \dot{I}_C Z_k = \dot{E}_C \end{aligned}$$
- **相量图**如图 4-9 所示。

	- **对于 B 相继电器**：
	    - 由于 $\dot{U}_{CA} = \dot{E}_{CA}$，因此 $\phi_B = \phi_k - 90^\circ - 30^\circ = \phi_k - 120^\circ$，则**动作条件**为：    $$U_{CA} I_B \cos(\phi_k - 120^\circ + \alpha) > 0$$
	    - 因此，为了在 $0^\circ \le \phi_k \le 90^\circ$ 时使 **B 相**的继电器能**动作**，需要选择 **$30^\circ \le \alpha \le 120^\circ$**。
	- **对于 C 相继电器**：
	    [原文标注：此处教材疑似存在笔误，公式中变量仍写作了 B 相，逻辑上应为 C 相]
	    - 由于 $\dot{U}_{AB} = \dot{E}_{AB}$，因此 $\phi_C = \phi_k - 90^\circ + 30^\circ = \phi_k - 60^\circ$，则**动作条件**为：$$U_{AB} I_C \cos(\phi_k - 60^\circ + \alpha) > 0$$
	    - 因此，为了在 $0^\circ \le \phi_k \le 90^\circ$ 时使 **C 相**的继电器能**动作**，需要选择 **$-30^\circ \le \alpha \le 60^\circ$**。
	- **综合**三相和各种两相短路的分析得出，当 $0^\circ \le \phi_k \le 90^\circ$ 时，使**方向继电器**在一切**相间故障**情况下都能动作的条件应为：
$$30^\circ \le \alpha \le 60^\circ$$
- 用于**相间短路**的模拟式**功率方向继电器**一般都提供了 **$\alpha = 30^\circ$** 和 **$\alpha = 45^\circ$** 两种内角，满足了上述要求。对于**微机保护**，任何值的内角都可以实现，可以很容易地按照被保护线路的实际**阻抗角**确定**功率方向继电器**的内角，不必考虑 $\phi_k$ 的变化。
>[!NOTE]- 注意
>以上讨论只是针对继电器在各种情况下可能**动作**的条件，而不是动作**最灵敏**的条件。为了减小**死区范围**，继电器动作最灵敏的条件应根据短路时使 $\cos(\phi_{sen} + \alpha) = 1$ 来决定。
