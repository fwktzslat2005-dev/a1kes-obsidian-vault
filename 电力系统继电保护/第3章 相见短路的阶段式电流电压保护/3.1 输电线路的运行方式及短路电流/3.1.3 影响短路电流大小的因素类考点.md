- 影响短路电流大小的因素如下：
	1. **运行方式**：通过式 $(3-1)$ 中的 $Z_s$ 体现。
	2. **短路类型**：通过式 $(3-1)$ 中的 $K_k$ 体现。
	3. **短路位置**：通过式 $(3-1)$ 中的 $Z_k$ 体现。
	4. **系统电压**：通过式 $(3-1)$ 中的 $E_{\phi}$ 体现。
	5.  **过渡电阻**：在**继电保护**的**短路计算**中，按照**金属性短路**来计算，不考虑**过渡电阻**的影响。
>[!NOTICE]
>虽然系统电压和过渡电阻会影响短路电流的大小，但是在**整定计算**中不考虑这两个因素的影响，**系统电压**按**额定电压**，**过渡电阻**按**没有过渡电阻**。
