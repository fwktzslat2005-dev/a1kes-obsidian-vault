## 4. 字数检查

- [ ] 第一章“微电网提出的背景知识”控制在 800-1000 字以内。

## 5. 设计假设是否标注清楚

- [ ] 直流小微电网母线电压未由任务书指定，正文写为设计假设，未固定具体电压等级。
- [ ] 接地方式未由任务书指定，正文写为“本方案选取 TN-S”。
- [ ] 通信协议未由任务书指定，正文写为“本方案设计选择”。
- [ ] EMS 硬件型号未由任务书指定，正文只给出合理硬件配置，不写具体品牌型号。
- [ ] 若老师指定 TT 或其他接地方式，后续需统一替换接地章节和接地图。

## 6. 是否方便后续手写和手画

- [ ] 一级、二级标题清晰。

- [ ] 电气链路用箭头表达，便于转化为手绘结构图。
- [ ] 运行步骤分节明确，便于逐段誊抄。
- [ ] 正文没有直接照抄参考作业文字。
