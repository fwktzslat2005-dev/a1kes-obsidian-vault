# 06_图纸手绘说明

本说明对应 `figures` 文件夹中的 4 张 SVG 草稿。所有图均按本科电气课程作业的黑白手绘风格设计，重点表现母线、支路、断路器、PCC、变流器、储能、负荷、接地符号和功率标注。

## 一、总体一次电气图手绘说明

对应文件：`figures/01_总体一次电气图.svg`

### 1. 从哪里开始画

先把 A4 纸横向使用。建议从纸张上半部分偏左位置开始画上级 380V 配电网，再向下画 PCC，并接到交流大微电网 380V 主母线。

整体顺序为：

1. 上级 380V 配电网。
2. PCC 并网点、并网断路器、保护与计量。
3. 交流大微电网 380V 主母线。
4. 交流大微电网各设备支路。
5. 右侧画交流小微电网和直流小微电网。
6. 最后补 EMS、三套协调控制器和虚线控制关系。

### 2. 母线怎样布置

交流大微电网主母线画成横向粗实线，放在页面中上部，标注“交流大微电网 380V 交流主母线”。这条母线是图中最重要的线，所有大微网支路都从它引出。

交流小微电网画在右上区域，内部再画一条较短的横向母线，标注“交流小微电网 380V AC 母线”。它通过一条联络支路接到交流大微电网主母线。

直流小微电网画在右下区域，内部画一条直流母线，标注“DC 母线”。直流母线通过双向 AC/DC 互联变换器接到交流大微电网主母线。

### 3. 每条支路依次画哪些设备

PCC 支路：

- 上级 380V 配电网符号。
- 并网断路器 QF0。
- PCC 标注。
- 保护/计量装置。
- 接入交流大微电网 380V 主母线。

交流大微电网 200kW 光伏支路：

- 从主母线向下引线。
- 画断路器 QF。
- 画 DC/AC 逆变器。
- 画 PV 方框，写“PV 200kW”和“DC/DC MPPT”。

交流大微电网 50kW 直驱风力发电支路：

- 从主母线向下引线。
- 画断路器 QF。
- 画 AC/DC-DC/AC 变流器。
- 画风机符号或风轮符号。
- 标注“直驱风机 50kW”。

交流大微电网 250kW×2h 储能支路：

- 从主母线向下引线。
- 画断路器 QF。
- 画 PCS。
- 画储能系统方框。
- 标注“250kW×2h”。

交流大微电网负荷支路：

- 重要负荷支路写“重要负荷 100kW”。
- 非重要负荷支路写“非重要负荷 100kW”。
- 两条支路都需要画断路器。

交流小微电网：

- 由主母线引出一条联络支路。
- 在联络支路上画“QF/STS”，表示联络断路器或静态开关。
- 小微网内部画 50kW 光伏、50kW 重要负荷、50kW×2h 储能。
- 小微网内部下方画“交流小微网协调控制器”。

直流小微电网：

- 从交流大微电网主母线引出直流小微网接入支路。
- 先画断路器 QF。
- 再画“双向 AC/DC”。
- 接入直流小微电网 DC 母线。
- DC 母线上画 100kW 光伏、80kW 充电负荷、100kW×2h 储能。
- 图中可加“IMD 绝缘监测”。

### 4. 必须写功率参数的位置

以下功率参数必须写清楚：

- 交流大微电网光伏：200kW。
- 交流大微电网直驱风机：50kW。
- 交流大微电网储能：250kW×2h。
- 交流大微电网重要负荷：100kW。
- 交流大微电网非重要负荷：100kW。
- 交流小微电网光伏：50kW。
- 交流小微电网重要负荷：50kW。
- 交流小微电网储能：50kW×2h。
- 直流小微电网光伏：100kW。
- 直流小微电网充电负荷：80kW。
- 直流小微电网储能：100kW×2h。

### 5. 断路器、接地符号和控制虚线

断路器必须画在 PCC、各电源支路、储能支路、负荷支路、小微电网联络支路和直流小微电网接入支路上。断路器可用小矩形或开关触点符号表示，旁边标 QF。

接地部分在总体一次图中只需简化表达，画出 N 线、PE 线、PE 接地符号，并标注“TN-S”。详细接地关系放到接地示意图中。

控制关系不要画得太密。EMS 放在图上方，三套协调控制器放在对应微电网附近，用虚线连接即可。虚线只表示通信和控制，不表示一次电气回路。

### 6. A4 图面整洁建议

- 先用铅笔轻画三块区域：左侧大微网支路、右上交流小微网、右下直流小微网。
- 主母线尽量水平，支路尽量竖直。
- 设备方框大小统一，不要随意倾斜。
- 功率参数写在设备名称下方，避免写到连线上。
- 控制虚线最后再画，且比一次线细。

## 二、设备并网结构图手绘说明

对应文件：`figures/02_设备并网结构图.svg`

### 1. 从哪里开始画

建议 A4 横向使用，将页面分成 6 个小框，每个小框画一种设备并网链路。每个小框只画主要设备，不画复杂保护细节。

### 2. 每个小图的画法

交流侧光伏并网链路：

- 依次画“光伏阵列 -> DC/DC MPPT -> 直流母线 -> 并网逆变器 -> 滤波/保护 -> 交流母线”。
- 在小图下方写“大微网 200kW，交流小微网 50kW”。

直流侧光伏接入链路：

- 依次画“光伏阵列 -> DC/DC MPPT -> DC 母线”。
- 标注“直流小微网光伏 100kW”。

直驱永磁同步风力发电链路：

- 依次画“风轮 -> PMSG 永磁同步发电机 -> 整流器 -> 直流环节 -> 逆变器 -> 滤波/保护 -> 交流母线”。
- 标注“直驱风力发电 50kW”。

交流侧储能双向 PCS 链路：

- 依次画“电池组及 BMS -> 双向 PCS -> 保护开关 QF -> 交流母线”。
- 标注“大微网 250kW×2h，交流小微网 50kW×2h”。

直流侧储能双向 DC/DC 链路：

- 依次画“电池组及 BMS -> 双向 DC/DC -> DC 母线”。
- 标注“直流小微网储能 100kW×2h”。

直流充电负荷链路：

- 依次画“DC 母线 -> 直流保护与充电控制设备 -> 充电负荷”。
- 标注“充电负荷 80kW”。

### 3. A4 图面整洁建议

- 六个小图用统一大小的方框分区。
- 每条链路从左到右画，箭头方向一致。
- 只写必要文字，不写长段说明。
- 母线画粗一些，变换器和保护设备用矩形表示。

## 三、接地示意图手绘说明

对应文件：`figures/03_接地示意图.svg`

### 1. 从哪里开始画

先画上级 380V 系统，再向右画 L1、L2、L3、N、PE 五条线。N 和 PE 必须分开画，这是 TN-S 的核心。

### 2. 接地关系怎样布置

左侧画电源中性点接地，N 线在电源侧接地。PE 线接总接地排，再接接地极。注意不要把 N 和 PE 在微电网内部再次混接。

中间画交流微电网侧，画出 380V AC 母线、N 线和 PE 线。逆变器、PCS、负荷箱等设备外壳都用细线接到 PE。

右侧画直流小微电网侧，画 DC+、DC- 两根母线，并画 IMD 绝缘监测装置。直流设备外壳、AC/DC、DC/DC、充电设备外壳统一接 PE。

### 3. 必须标注的内容

- “TN-S：N 与 PE 分开”。
- “电源中性点接地”。
- “PE 总接地排”。
- “设备外壳接 PE”。
- “直流侧 IMD 绝缘监测”。
- “并网与离网状态下 PE 均保持连续”。

### 4. 不要混画的内容

正文最终选取 TN-S，因此接地图中不要同时画 TT 或 IT。其他可选接地方式只在文字说明中提到，不出现在最终接地图中。

## 四、EMS 与通信结构图手绘说明

对应文件：`figures/04_EMS与通信结构图.svg`

### 1. 从哪里开始画

这张图按从上到下的分层结构画。先在最上方画 EMS、监控工作站、数据库和 UPS。中间画三套协调控制器。底层画设备控制器、智能电表、保护测控装置和断路器状态量。

### 2. 三层结构怎样布置

顶层：

- EMS。
- 监控工作站/HMI。
- 数据库。
- UPS 电源。

中层：

- 交流大微电网协调控制器。
- 交流小微电网协调控制器。
- 直流小微电网协调控制器。

底层：

- 光伏逆变器。
- 风电变流器。
- 储能 PCS。
- BMS。
- 双向 AC/DC。
- 双向 DC/DC。
- 充电控制器。
- 智能电表。
- 保护测控装置。
- 通信网关。
- 工业交换机。
- 断路器状态量。

### 3. 通信线怎样画

EMS 到三套协调控制器之间画实线或较粗虚线，并标注“工业以太网”。协调控制器到设备层之间画虚线，并标注“现场总线/工业以太网”。

通信线旁边可写上传和下发信息：

- 上传：电压、电流、功率、SOC、开关状态、告警。
- 下发：并离网命令、储能功率、光伏限发、负荷切除、充电调节。

### 4. 硬件简表怎样画

图右侧留一小块空白，画一个简表，写：

- 工控机/服务器：运行 EMS。
- 监控站：显示状态和告警。
- 交换机/网关：通信汇聚转换。
- 电表/保护：采集和保护动作。

### 5. A4 图面整洁建议

- 三层之间留足空白，避免连线交叉太多。
- 同一层方框高度保持一致。
- 通信协议写在线旁边，不要写在设备框里。
- 设备层对象较多，可以分两行画。
