# 01_系统总体设计方案

## 1. 总体设计目标

本设计对象为一个接入 380V 配电网的交直流混合微电网。系统整体对外表现为交流大微电网，交流大微电网内部包含一个交流小微电网和一个直流小微电网。设计重点是使系统拓扑清楚、设备容量与任务书一致、一次图便于手画、控制层级便于后续展开。

推荐采用的总体结构为：

`380V 配电网 -> PCC 并网点 -> 交流大微电网 380V 主母线 -> 各分支设备和两个小微电网`

其中，交流小微电网以交流馈线方式接入交流大微电网；直流小微电网通过双向 AC/DC 互联变换器接入交流大微电网。

## 2. 交流大微电网主母线与 PCC 接入方式

交流大微电网设置一段 380V 交流主母线，作为全系统对外并网和内部功率汇集的核心母线。主母线通过 PCC 接入 380V 配电网。

PCC 接入建议按以下顺序绘制：

`380V 配电网 -> 隔离开关 QS0 -> PCC 断路器 QF0 -> 计量/保护测控装置 -> 交流大微电网 380V 主母线`

PCC 点应具备以下功能：

- 并网和离网的物理分合点。
- 电压、频率、相位、电流和功率的检测点。
- 并网同步判断点。
- 外部电网故障时的快速解列点。
- 配电网削峰填谷时的功率交换计量点。

交流大微电网 380V 主母线上设置以下支路：

- 200kW 光伏发电支路。
- 50kW 直驱风力发电支路。
- 250kW*2h 储能系统支路。
- 100kW 重要负荷支路。
- 100kW 非重要负荷支路。
- 交流小微电网接入支路。
- 直流小微电网接入支路。
- 交流大微电网协调控制器的测控通信接入。

## 3. 交流小微电网接入方式

交流小微电网内部设置一段 380V 交流母线，通过交流馈线接入交流大微电网主母线。建议手画结构为：

`交流大微电网 380V 主母线 -> 交流小微网馈线断路器 QF_ACM -> 交流小微电网 380V 母线`

交流小微电网 380V 母线上设置：

- 50kW 光伏发电支路。
- 50kW*2h 储能系统支路。
- 50kW 重要负荷支路。
- 交流小微电网协调控制器。

运行原则：

- 并网运行时，交流小微电网通过馈线与交流大微电网交换功率。
- 离网运行时，交流小微电网馈线断路器断开，小微网由本地储能建立电压和频率。
- 交流小微电网的重要负荷为保供对象，不设置非重要负荷支路。

## 4. 直流小微电网接入方式

直流小微电网内部设置一段直流母线。任务书未指定直流母线电压，因此第一阶段不固定 750V、800V 等具体电压，只在图中标为“直流母线”。

直流小微电网通过双向 AC/DC 互联变换器接入交流大微电网。建议手画结构为：

`交流大微电网 380V 主母线 -> 直流小微网接入断路器 QF_DCM -> 双向 AC/DC 互联变换器 -> 直流小微电网 DC 母线`

直流小微电网 DC 母线上设置：

- 100kW 光伏发电支路。
- 100kW*2h 储能系统支路。
- 80kW 充电负荷支路。
- 直流小微电网协调控制器。

运行原则：

- 并网运行时，双向 AC/DC 互联变换器控制交流侧有功、无功交换，并稳定直流侧功率平衡。
- 离网运行时，直流小微电网由本地储能或互联变换器控制直流母线电压。
- 80kW 充电负荷具有可调节特性，功率缺额时可降低充电功率或暂时切除。

## 5. 各类设备并网电气链路

### 5.1 光伏发电链路

交流大微电网 200kW 光伏：

`PV 阵列 -> DC/DC MPPT -> DC/AC 并网逆变器 -> 交流断路器 -> 交流大微电网 380V 主母线`

交流小微电网 50kW 光伏：

`PV 阵列 -> DC/DC MPPT -> DC/AC 并网逆变器 -> 交流断路器 -> 交流小微电网 380V 母线`

直流小微电网 100kW 光伏：

`PV 阵列 -> DC/DC MPPT -> 直流断路器 -> 直流小微电网 DC 母线`

说明：

- 交流侧光伏采用并网逆变器接入交流母线。
- 直流侧光伏优先采用 DC/DC MPPT 接入直流母线。
- 并网时光伏一般采用最大功率跟踪或限功率 PQ 控制。
- 离网且功率盈余时，光伏应支持限发或退出部分出力。

### 5.2 直驱风力发电链路

交流大微电网 50kW 直驱风机建议采用永磁同步发电机和全功率变流器结构：

`风轮 -> 永磁同步发电机 -> AC/DC 整流器 -> DC 母线环节 -> DC/AC 并网逆变器 -> 交流断路器 -> 交流大微电网 380V 主母线`

说明：

- 该链路适合表现直驱风机没有齿轮箱、通过全功率变流器并入交流母线。
- 并网运行时风电可按最大功率跟踪或限功率控制。
- 离网运行且功率盈余时，风机应具备降载、限功率或停机控制。

### 5.3 储能系统链路

交流大微电网 250kW*2h 储能：

`电池组 -> BMS -> 双向 DC/DC -> PCS 双向变流器 -> 交流断路器 -> 交流大微电网 380V 主母线`

交流小微电网 50kW*2h 储能：

`电池组 -> BMS -> 双向 DC/DC -> PCS 双向变流器 -> 交流断路器 -> 交流小微电网 380V 母线`

直流小微电网 100kW*2h 储能：

`电池组 -> BMS -> 双向 DC/DC -> 直流断路器 -> 直流小微电网 DC 母线`

说明：

- 交流侧储能 PCS 在并网时可采用 PQ 控制，实现充放电功率调节。
- 交流侧储能 PCS 在离网时可切换为 V/f 控制，支撑交流母线电压和频率。
- 直流侧储能通过双向 DC/DC 控制直流母线电压或按 EMS 指令进行充放电。

### 5.4 负荷链路

交流大微电网重要负荷：

`交流大微电网 380V 主母线 -> 重要负荷断路器 -> 100kW 重要负荷`

交流大微电网非重要负荷：

`交流大微电网 380V 主母线 -> 非重要负荷断路器 -> 100kW 非重要负荷`

交流小微电网重要负荷：

`交流小微电网 380V 母线 -> 重要负荷断路器 -> 50kW 重要负荷`

直流小微电网充电负荷：

`直流小微电网 DC 母线 -> 直流断路器/充电控制器 -> 80kW 充电负荷`

## 6. 重要负荷与非重要负荷离网处理原则

离网运行时，应以保证重要负荷连续供电为首要目标。

功率缺额时，处理顺序建议为：

1. EMS 和协调控制器判断外部电网不可用或系统已进入离网状态。
2. 储能快速切换为支撑控制，维持交流母线电压频率或直流母线电压。
3. 优先保障 100kW 交流大微电网重要负荷和 50kW 交流小微电网重要负荷。
4. 降低或暂停直流小微电网 80kW 充电负荷。
5. 切除交流大微电网 100kW 非重要负荷。
6. 若仍功率不足，则按储能 SOC 和发电能力进一步限负荷，避免母线电压或频率失稳。

功率盈余时，处理顺序建议为：

1. 优先提高储能充电功率。
2. 若储能接近 SOC 上限，则限制光伏出力。
3. 必要时限制风机出力或停机。
4. 在满足安全条件时恢复可调充电负荷。

## 7. 控制层级建议

本设计采用分层控制结构，便于后续手写报告和 EMS 图绘制：

- 上层：微电网能量管理系统 EMS，负责运行模式判断、经济调度、削峰填谷、SOC 管理、负荷优先级管理。
- 中层：交流大微电网协调控制器、交流小微电网协调控制器、直流小微电网协调控制器，负责本区域设备协调、模式切换和保护联动。
- 底层：光伏逆变器、风电变流器、储能 PCS、双向 AC/DC、双向 DC/DC、充电控制器、断路器和测控保护装置。

并网时推荐控制方式：

- 光伏和风电：MPPT 或限功率 PQ 控制。
- 储能：PQ 控制，按 EMS 指令充放电。
- 双向 AC/DC：按有功、无功或直流电压目标运行。

离网时推荐控制方式：

- 交流大微电网：由大微网储能 PCS 或主控电源形成 V/f 支撑。
- 交流小微电网：由小微网储能 PCS 形成 V/f 支撑。
- 直流小微电网：由直流储能双向 DC/DC 或互联变换器维持直流母线电压。

## 8. 接地方式可选方案与推荐方案

### 8.1 可选方案

低压微电网常见可选接地方式包括：

- TT：电源中性点接地，设备外露可导电部分通过独立接地装置接地。
- TN-S：电源中性点接地，N 线和 PE 线全程分开，设备外壳接 PE。
- IT：电源侧不直接接地或经高阻接地，配合绝缘监测装置运行。

### 8.2 本阶段推荐方案

本阶段默认推荐交流部分采用 TN-S 接地方式，理由如下：

- 适合低压 380V 交流配电系统表达。
- N 线和 PE 线分开，图中表示清楚。
- 便于说明设备外壳保护接地和漏电/接地故障保护。
- 便于在手画一次图和接地示意图中统一表达。

直流侧推荐表达为：

- 直流母线设置绝缘监测装置 IMD。
- 直流设备外壳、充电设备外壳、变换器外壳统一接 PE。
- 直流正负极不在第一阶段擅自指定直接接地，避免与课程未指定要求冲突。

最终接地图统一按以下原则表达：

`交流系统 TN-S：N 与 PE 分开；所有设备外壳接 PE；PE 接总接地排；直流侧设备外壳接同一 PE，总体设绝缘监测。`

如果老师或课程资料明确要求 TT，则后续应将全文和图纸中的接地方式统一改为 TT，不同时保留 TN-S 与 TT 两套结论。
