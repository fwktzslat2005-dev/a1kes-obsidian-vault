# 03_图纸清单与绘制计划

## 1. 绘图总原则

- 图纸用于后续手画，不在第一阶段绘制最终图。
- 每张图应优先保证拓扑清楚、容量标注完整、符号便于手画。
- 所有容量必须按 `RWS.docx` 标注，不使用 `CKZY.pdf` 示例参数。
- 强电一次线用实线表示，通信线用虚线表示，控制器与 EMS 可用矩形框表示。
- 接地符号在接地图中集中表达，在总体一次图中可简化标注 PE 或接地符号。

## 2. 图 1：总体一次电气图

表现整个交直流混合微电网的一次主结构，说明系统如何作为交流大微电网接入 380V 配电网，以及交流小微电网和直流小微电网如何接入交流大微电网。

- 交流小微电网 380V 母线。
- 直流小微电网 DC 母线。

开关和保护：

- PCC 隔离开关 QS0。
- PCC 断路器 QF0。

- 交流小微电网馈线断路器 QF_ACM。

- 计量和保护测控装置。

交流大微电网设备：

- 200kW 光伏发电一路。
- 50kW 直驱风力发电一路。
- 250kW*2h 储能系统一路。
- 100kW 重要负荷一路。
- 100kW 非重要负荷一路。
- 交流大微电网协调控制器。

交流小微电网设备：

直流小微电网设备：

- EMS 与三套协调控制器的通信虚线。

### 2.3 建议手画布局

- 左侧画 380V 配电网和 PCC。

- 右上侧画交流小微电网。

## 3. 图 2：各类设备并网结构示意

### 3.1 图纸目的

分别说明光伏、直驱风机、储能、负荷和充电负荷的电气接入链路。该图可分成若干小图，便于手画和正文说明对应。

### 3.2 光伏并网结构

交流侧光伏：

`PV 阵列 -> DC/DC MPPT -> DC/AC 逆变器 -> 交流断路器 -> 交流母线`

需要标注：

- 交流大微电网光伏：200kW。
- 交流小微电网光伏：50kW。
- DC/DC MPPT。
- DC/AC 逆变器。
- 交流断路器。

直流侧光伏：

`PV 阵列 -> DC/DC MPPT -> 直流断路器 -> DC 母线`

需要标注：

- 直流小微电网光伏：100kW。
- DC/DC MPPT。
- 直流断路器。

### 3.3 直驱风力发电结构

`风轮 -> 永磁同步发电机 PMSG -> AC/DC 整流器 -> DC 环节 -> DC/AC 逆变器 -> 交流断路器 -> 交流大微电网 380V 主母线`

需要标注：

- 直驱风力发电：50kW。
- 永磁同步发电机。
- 全功率变流器。
- 交流断路器。
- 并入交流大微电网 380V 主母线。

### 3.4 储能系统结构

交流侧储能：

`电池组 -> BMS -> 双向 DC/DC -> PCS -> 交流断路器 -> 交流母线`

需要标注：

- 交流大微电网储能：250kW*2h。
- 交流小微电网储能：50kW*2h。
- BMS。
- 双向 DC/DC。
- PCS。
- 交流断路器。

直流侧储能：

`电池组 -> BMS -> 双向 DC/DC -> 直流断路器 -> DC 母线`

需要标注：

- 直流小微电网储能：100kW*2h。
- BMS。
- 双向 DC/DC。
- 直流断路器。

### 3.5 负荷和充电负荷结构

交流重要负荷：

`交流母线 -> 负荷断路器 -> 重要负荷`

标注：

- 交流大微电网重要负荷：100kW。
- 交流小微电网重要负荷：50kW。

交流非重要负荷：

`交流大微电网 380V 主母线 -> 负荷断路器 -> 非重要负荷`

标注：

- 非重要负荷：100kW。
- 离网时可切除。

直流充电负荷：

`DC 母线 -> 直流断路器/充电控制器 -> 充电负荷`

标注：

- 充电负荷：80kW。
- 功率缺额时可降低功率或暂停。

## 4. 图 3：微电网接地示意

### 4.1 图纸目的

表现本设计推荐接地方案，并保证后续正文和图纸前后一致。

### 4.2 推荐表达

交流部分采用 TN-S：

- 380V 系统中性点接地。
- N 线和 PE 线分开。
- 所有交流设备外壳接 PE。
- PE 接总接地排。
- 总接地排接接地极。

直流部分采用保护接地加绝缘监测：

- 直流正负母线不在第一阶段指定直接接地。
- 设置直流绝缘监测装置 IMD。
- 直流设备外壳、充电桩外壳、双向 AC/DC 外壳接 PE。
- 直流侧 PE 与交流侧 PE 接入同一保护接地系统。

### 4.3 必须画出的符号

- 接地极符号。
- 总接地排。
- N 线。
- PE 线。
- N/PE 分离标识。
- 设备外壳保护接地。
- 直流绝缘监测装置 IMD。
- 双向 AC/DC 互联变换器外壳接地。

## 5. 图 4：能量管理系统与通信结构图

### 5.1 图纸目的

表现 EMS、三套协调控制器、设备控制器和保护测控装置之间的信息流和控制关系，满足任务书对“具体通信结构”和“硬件配置”的要求。

### 5.2 必须画出的层级

上层：

- 微电网能量管理系统 EMS。
- 工控机或服务器。
- 人机界面 HMI。
- 数据库或历史数据存储。

中层：

- 交流大微电网协调控制器。
- 交流小微电网协调控制器。
- 直流小微电网协调控制器。

底层：

- 光伏逆变器控制器。
- 风电变流器控制器。
- 储能 PCS 控制器。
- BMS。
- 双向 AC/DC 控制器。
- 双向 DC/DC 控制器。
- 充电控制器。
- 保护测控装置。
- 智能电表。
- 断路器执行机构。

### 5.3 通信线标注

建议在图中用虚线画通信线，并标注：

- EMS 与协调控制器：以太网或工业以太网。
- 协调控制器与设备控制器：RS485/CAN/以太网，可写为“现场总线/以太网”以避免型号过细。
- 计量保护装置向 EMS 上传电压、电流、频率、功率、SOC、开关状态和告警。
- EMS 下发并离网模式、储能功率、光伏限发、负荷切除、充电负荷调节等指令。

### 5.4 硬件配置建议

图中可标注以下硬件：

- EMS 工控机或服务器 1 套。
- HMI 显示终端 1 套。
- 交换机 1 套。
- 三套微电网协调控制器。
- 智能电表和保护测控装置若干。
- 设备控制器随逆变器、PCS、BMS、变换器配置。

### 6.3 离网功率平衡流程建议

功率缺额：

`检测功率缺额 -> 判断储能 SOC -> 储能放电 -> 降低充电负荷 -> 切除非重要负荷 -> 保持重要负荷供电 -> 告警`

功率盈余：

`检测功率盈余 -> 储能充电 -> 恢复可调充电负荷 -> 限制光伏出力 -> 限制风机出力 -> 保持母线稳定`

### 6.4 削峰填谷流程建议

`采集配电网负荷和电价/时段 -> 判断峰段或谷段 -> 峰段储能放电并减少购电 -> 谷段储能充电并吸收低谷电能 -> 实时修正功率指令 -> 记录运行数据`
