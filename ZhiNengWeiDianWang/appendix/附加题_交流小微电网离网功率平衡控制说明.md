# 附加题：交流小微电网离网功率平衡控制说明

## 1. 附加题目的

本附加题选择“交流小微电网离网功率平衡控制”。程序目标不是建立精细电磁暂态模型，而是用 Python 3 展示协调控制器如何根据光伏功率、重要负荷功率和储能 SOC 作出控制判断，使交流小微电网在离网运行时尽量保持有功功率平衡。

该附加题与正文设计保持一致：交流小微电网只包含 50 kW 光伏、50 kW 重要负荷、50 kW×2 h 储能系统和 1 套协调控制器。该小微电网离网运行时不与交流大微电网交换功率。

## 2. 交流小微电网参数

| 项目 | 参数 |
| --- | --- |
| 光伏发电 | 50 kW |
| 重要负荷 | 50 kW |
| 储能系统 | 50 kW×2 h |
| 储能额定能量 | 100 kWh |
| 协调控制器 | 1 套 |
| 运行状态 | 离网运行，不与交流大微电网交换功率 |

注意：任务书没有给交流小微电网设置非重要负荷，因此本程序不设计“切除非重要负荷”作为正常控制措施。当光伏不足且储能 SOC 已达到最低允许值时，程序输出功率缺额告警，提示重要负荷无法持续完全供电，需要上级应急处理。

## 3. 控制对象及控制角色

离网运行时，储能 PCS 作为主控电源，采用 V/f 控制，用于维持交流小微电网母线电压和频率稳定。程序中不直接仿真电压和频率动态，而是用储能有功功率指令表示储能对功率缺额或盈余的响应。

光伏逆变器作为受控电源运行。光照充足且系统可以吸收功率时，光伏按最大功率跟踪运行；当光伏功率大于负荷和储能可吸收功率时，协调控制器下发光伏限发指令。

协调控制器实时读取 `P_pv`、`P_load` 和 `SOC`，根据功率平衡关系计算储能充放电指令、光伏限发指令和告警状态。

## 4. 功率符号约定

程序和说明统一采用以下符号：

- `P_pv`：光伏当前可发功率，单位 kW。
- `P_load`：重要负荷功率，单位 kW。
- `P_ess`：储能功率，单位 kW。
- `P_ess > 0`：储能放电。
- `P_ess < 0`：储能充电。
- `P_curtail`：光伏限发功率，单位 kW。
- `SOC`：储能荷电状态。
- `P_balance_error`：最终剩余功率不平衡量。

功率平衡关系为：

`P_pv_actual + P_ess - P_load = P_balance_error`

其中：

`P_pv_actual = P_pv - P_curtail`

正常稳定运行时，协调控制器尽量使：

`P_balance_error = 0`

## 5. 功率平衡控制逻辑

当 `P_pv = P_load` 时，光伏刚好满足重要负荷需求。此时储能功率指令为 0，光伏不需要限发，系统保持正常离网供电状态。

当 `P_pv < P_load` 时，系统出现功率缺额。协调控制器计算 `P_deficit = P_load - P_pv`。若 `SOC > SOC_min`，则储能 PCS 放电补足缺额，但放电功率不能超过 50 kW，且不能使 SOC 低于最低允许值。若储能放电后仍存在缺额，程序输出功率缺额告警。

当 `P_pv > P_load` 时，系统出现功率盈余。协调控制器计算 `P_surplus = P_pv - P_load`。若 `SOC < SOC_max`，则储能吸收盈余功率进行充电，但充电功率不能超过 50 kW，且不能使 SOC 超过最高允许值。若储能充电受限后仍有盈余，则通过 `P_curtail` 削减光伏实际出力。

## 6. 功率缺额时的处理步骤

1. 读取当前 `P_pv`、`P_load` 和 `SOC`。
2. 判断 `P_pv < P_load`，计算缺额功率。
3. 检查储能 SOC 是否高于最低允许值。
4. 若允许放电，则由储能补足缺额，`P_ess > 0`。
5. 若储能功率不足或 SOC 已到下限，则输出“功率缺额告警”。
6. 告警状态说明重要负荷存在供电风险，需要上级应急处理。

## 7. 功率盈余时的处理步骤

1. 读取当前 `P_pv`、`P_load` 和 `SOC`。
2. 判断 `P_pv > P_load`，计算盈余功率。
3. 检查储能 SOC 是否低于最高允许值。
4. 若允许充电，则由储能吸收盈余功率，`P_ess < 0`。
5. 若储能已接近充满或充电功率达到上限，则执行光伏限发。
6. 通过储能充电和光伏限发共同保证离网交流母线功率基本平衡。

## 9. 程序流程说明

程序核心函数为：

`power_balance_control(p_pv, p_load, soc, dt)`

该函数输入当前光伏可发功率、重要负荷功率、储能 SOC 和控制周期，输出储能功率指令、光伏限发功率、更新后的 SOC、功率平衡误差、控制状态和告警状态。

一日仿真函数按 24 个时间点依次调用单步控制函数。每个时段结束后，新的 SOC 作为下一时段的初始 SOC。程序最后保存 `仿真结果.csv`，并生成三张结果图。

## 10. 仿真场景说明

仿真设置 24 个时间点，模拟一天内光伏和负荷变化。夜间光伏为 0，重要负荷由储能供电；上午光伏逐渐升高；中午光伏接近 50 kW；下午光伏下降；晚间再次由储能供电。

光伏功率数组和负荷功率数组仅用于演示控制逻辑，不代表真实测量数据。场景中特意包含两个典型情况：一是夜间储能 SOC 降至下限后出现功率缺额告警；二是中午储能接近充满后出现光伏限发。

## 11. 仿真结果分析

仿真结果表明，当光伏不足时，储能 PCS 按 `P_ess > 0` 放电补足缺额，使重要负荷尽量保持供电。当 SOC 仍高于最低允许值时，功率平衡误差可被控制在 0 附近。

当 SOC 降至最低允许值后，储能不能继续深度放电。此时若光伏仍小于重要负荷，程序会输出功率缺额告警，说明重要负荷存在供电风险。由于任务书没有给交流小微电网配置非重要负荷，程序没有设计切除非重要负荷的逻辑。

当光伏盈余时，储能按 `P_ess < 0` 充电吸收多余功率。若 SOC 达到最高允许值，储能不再继续吸收功率，协调控制器通过光伏限发保持功率平衡，避免离网母线出现功率过剩。

## 12. 可抄写到报告附录中的总结文字

本附加题程序采用简化的能量层功率平衡模型，模拟交流小微电网在离网运行时的协调控制过程。储能 PCS 作为主控电源承担 V/f 控制任务，光伏逆变器根据协调控制器指令采用最大功率跟踪或限功率运行。协调控制器根据光伏功率、重要负荷功率和储能 SOC 判断功率缺额或盈余，并给出储能充放电和光伏限发指令。

仿真结果说明，储能能够在光伏不足时放电补偿缺额，在光伏盈余时充电吸收功率。当 SOC 达到下限后，系统不能虚构非重要负荷切除措施，而应输出重要负荷供电风险告警；当 SOC 达到上限后，需要限制光伏出力。该程序体现了交流小微电网离网运行时功率平衡控制的基本思路。
