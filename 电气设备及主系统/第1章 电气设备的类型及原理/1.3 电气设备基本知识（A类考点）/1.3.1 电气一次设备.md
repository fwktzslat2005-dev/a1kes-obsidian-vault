将*生产*、*变换*、*输送*、*分配*和*使用*电能的设备称为**电气一次设备**。

# 一、生产和变换电能的设备
- **发电机**将机械能转换成电能，
- **电动机**将电能转换成机械能，
- 变压器**将电压升高或降低以满足输配电需要。

# 二、接通或断开电路的开关电器
- **断路器** （ $QF$ ）：配有灭弧装置，是电力系统中最重要的控制和保护电器。
	- 开关功能最完善~灭弧能力($SF_6$ /真空 $\Rightarrow$ 灭弧室)最好
	- 接通或断开正常工作电流 ~ **控制作用**
	- 接通或断开故障后短路电流 ~ **保护作用**
- **隔离开关**（ $QS$ ）：没有灭弧装置，一般只有电路断开的情况下才能操作。
	- 一般一个 $QF$ 配两个 $QS$ 
	- 检修设备时：**明显且可靠的断点** $\Rightarrow$ 隔离电压
	- 开断*小电流* $\le$ 5$A$
	- 作为操作电器：进行电路的切换操作 （“**等电位**”时可以开断）
- 此外，还有**负荷开关/接触器**、**熔断器**等（$FC$回路），它们用于正常或事故时将电路闭合或断开。
	- **负荷开关/接触器**：接通或断开正常工作电流
	- **熔断器**：断开故障后短路电流、过负荷电流

# 三、限制故障电流和防御过电压的电器
- 限制短路电流的**电抗器（串联）**（*只会出现在电缆*（架空线需要电容器））
	- 若电抗器与对地电容串联：抑制涌流、滤波器
- 防御过电压的**避雷器**（*没有额度电流参数 /无需短路状态检验*~ 正常时无电流流通）等。

# 四、载流导体
- **母线**、**裸导体**、**架空线**、**电缆**（*控制电缆属于二次设备*）等。
	- 导线：
		- 软导体：不做动稳定校验
		- 硬导体：     电压（电晕）   载流量
			- 矩形：$110\text{kV}$ 以下      $4000\text{A}$ 以下   表面积大，散热好，适合屋内
			- 槽形：$110\text{kV}$ 一下      $4000\sim8000\text{A}$
			- 管形：$110\text{kV}$及以上   $4000\text{A}$以上

# 五、互感器
- **电压互感器**($TV$)将交流高压变成低压 ($\boldsymbol{100\text{V}}$ 或 $\boldsymbol{100/\sqrt{3}\text{V}}$)，供电给测量仪表和继电保护装置的电压线圈。（一次侧并联接入/匝数多 $\Rightarrow$ 一次侧电压高（*电网电压*），二次侧近似开路）
	- $I_2 \approx0$ ，$I_1 <I_2\approx0 \Rightarrow$ 没有额定参数$I_N$，不用做短路状态校验
- **电流互感器**($TA$)将交流大电流变成小电流 ($5\text{A}$ 或 $1\text{A}$)，供电给测量仪表和继电保护装置的电流线圈。（一次侧串联接入/匝数少 $\Rightarrow$ 一次侧电压低，二次侧近似短路）

# 六、无功补偿设备
- **调相机**、**并联电容器**、**串联电容器**、**并联电抗器**、**静止无功补偿器** ($SVC$)、**静止无功发生器** ($SVG$)、**静止同步补偿器** ($STATCOM$) 等，*用来补偿电力系统的无功功率 ，以降低有功损耗和维持系统稳定性*

# 七、接地装置
- 包括电力系统中性点的**工作接地**、**防雷接地**、**保护接地**、**保护接零**等，均需同埋入地中的接地装置相连接。

# 八、绝缘子、套管
- 用来支持和固定**载流导体**，并使**载流导体**与地绝缘，或使装置中不同电位的**载流导体**间绝缘。
	- 绝缘子没有$I_N$ 。

# 九、中性点设备
- **消弧线圈**、**接地电阻**、**接地变压器**等。
	- 单元接线中发电机中性点~欠补偿
