- **电磁式电压互感器**电压等级越高对绝缘要求也越高，体积越庞大，成本随之增加，给布置和运行带来不便。
# 一、工作原理

**电容式电压互感器**工作原理如图 $1\text{-}51$ 所示。

## 1.电容分压原理
- 如图 $1\text{-}51\text{ (a)}$ 所示。![[图1-51 电容式电压互感器工作原理.png|center|613]]
$$\dot{U}_2 = \dot{U}_{C_2} = \frac{C_1}{C_1 + C_2} \dot{U}_1 = K \dot{U}_1$$
	式中，**分压比**为：$$K = \frac{C_1}{C_1 + C_2}$$
## 2.等效含源一端口网络
- 根据戴维南定理，分压器可等效为一个电压源。如图 $1\text{-}51\text{ (b)}$ 所示。 其**内阻抗** $Z_i$ 为：
$$Z_i = \frac{1}{\text{j}\omega(C_1 + C_2)}$$
- 当负载电流流过时，在 $Z_i$ 上产生压降，使 $U_{C_2}$ 和 $\frac{C_1}{C_1 + C_2}U_1$ 在数值和相位上产生误差，负载电流越大，误差越大。
## 3.串联补偿电感
- 如图 $1\text{-}51\text{ (c)}$ 所示。为减小 $Z_i$ 以减小误差，需在回路中串联**补偿电感** $L$。此时总内阻抗为：
$$Z_i = \text{j}\omega L + \frac{1}{\text{j}\omega(C_1 + C_2)} = \text{j}\left[\omega L - \frac{1}{\omega(C_1 + C_2)}\right]$$
- 当满足**补偿条件**（即回路发生串联谐振）时：
$$\omega L = \frac{1}{\omega(C_1 + C_2)} \text{，即 } L = \frac{1}{\omega^2(C_1 + C_2)}$$
  此时，$Z_i = 0$。
#### 运行特性总结：
- **理想状态**：在谐振状态下，输出电压与负荷大小无关，测量误差最小。
- **实际局限**：由于电容器存在损耗、电抗器也存在电阻，物理上不可能使内阻抗完全为零，故仍存在微小误差。
- **结构优化**：为进一步减小分压器输出电流从而减小误差，测量仪表需经**中间电磁式电压互感器**升压后与分压器连接。
# 二、基本结构
- **电容式电压互感器**基本结构原理如图 $1\text{-}52$ 所示。![[图1-52 电容式电压互感器基本结构原理图.png|center|349]]
	- **二次侧发生短路**时，短路电流可达额定电流的几十倍，此电流将产生很高的**谐振过电压**，为此在**电容** $L'$, $L$ 上并联**放电间隙**。
	- 在一次电压或二次电流剧变时（二次短路或断开等冲击），由于**非线性电抗**（**TV 的一次绕组**）的饱和，可能激发产生**分数次谐波**（常见的是 $1/3$ 次谐波）**产生的铁磁谐振过电压**和**大电流**，对**互感器**、仪表和继电器将造成危害，并可能导致**保护装置**误动作（**电压互感器开口三角形绕组**会出现**零序电压**）。
- **抑制措施**：
	- 为了抑制**次谐波**的产生，常在互感器二次侧设**阻尼电阻** $D$，目前有**经常接入**和**谐振时自动接入**两种方式。
- 图中所示为**谐振阻尼器** 其电气构成逻辑如下：
	- **并联支路**：由一个**电感**和一个**电容并联**构成。
	- **串联组合**：该并联支路整体再与**阻尼电阻**串联。
# 三、优点
- 结构简单、质量轻、体积小、占地小、成本低。
# 四、缺点
- 输出容量小、误差大；
- 当**环境温度**和**频率**变动时，对误差影响较大；
- **暂态特性**不如**电磁式**。

# 五、应用
- $110\text{kV}$ 及以上电压等级。
- $110 \sim 220\text{kV}$ 当**准确级**和**容量**满足要求的前提下，优先选用**电容式电压互感器**
- $500\text{kV}$ 均为电容式。
