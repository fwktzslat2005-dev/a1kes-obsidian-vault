# 一、 火电厂分类
火力发电厂（Thermal Power Plant）是利用可燃物燃烧时产生的热能来生产电能的工厂。根据不同的分类标准，主要包含以下几种：

## 按输出能源分类（核心重点）：
- **凝汽式发电厂**：专门生产电能。汽轮机内作功后的蒸汽全部排入凝汽器冷却成水。由于大量气化潜热被冷却水带走，系统热效率较低（通常在 $30\% \sim 40\%$）。
- **热电厂（热电联产）**：同时生产电能和热能。汽轮机在发电的同时，抽出一部分作功后的蒸汽向工业或民用热用户供热。由于减少了凝汽冷源损失，热效  率较高（通常可达 $60\% \sim 70\%$，甚至更高）。
## 按原动机分类：
- **凝气式汽轮机发电厂**：以蒸汽轮机为原动机，是目前火电厂最主要的形式。
- **燃气轮机发电厂**：以燃气轮机为原动机，启停快。简单循环热效率较低（约 $20\% \sim 30\%$），但与汽轮机组成**燃气-蒸汽联合循环（CCGT）**时，综合热效率可高达 $50\% \sim 60\%$ 以上。
- **内燃机发电厂**：主要用作移动电源、备用电源或孤立小电网供电，单机容量通常较小。
## 按燃料种类分类
燃煤发电厂（我国主力）、燃油发电厂、燃气发电厂、余热发电厂等，此外还有垃圾及工业废料的发电厂。
## 按蒸汽压力和温度分类
- 机组参数（蒸汽压力和温度）越高，机组的热力循环效率也相应越高：
	- **中低压机组**：压力约 $1.2 \sim 3.92\text{MPa}$，温度约 $300 \sim 450^{\circ}\text{C}$，单机功率通常 $\le 50\text{MW}$。
	-  **高压机组**：压力约 $8 \sim 10\text{MPa}$，温度约 $500 \sim 540^{\circ}\text{C}$，单机功率约 $50 \sim 100\text{MW}$。
	- **超高压机组**：压力约 $13 \sim 14\text{MPa}$，温度约 $535 \sim 540^{\circ}\text{C}$，单机功率约 $125 \sim 200\text{MW}$。
	- **亚临界机组**：压力约 $16 \sim 17\text{MPa}$，温度约 $535 \sim 540^{\circ}\text{C}$，单机功率通常为 $300 \sim 600\text{MW}$。
	- **超临界机组**：压力一般在 $24 \sim 25\text{MPa}$，温度约 $535 \sim 566^{\circ}\text{C}$，单机功率通常为 $600 \sim 800\text{MW}$。
- **超超临界机组**：压力 $\ge 25\text{MPa}$（多在 $25 \sim 31\text{MPa}$），温度 $\ge 593^{\circ}\text{C}$（通常为 $600^{\circ}\text{C}$ 及以上），单机功率一般在 $1000\text{MW}$ 及以上，是我国目前新建火电厂的主力大型机组。

# 二、 火电厂电能生产过程
火电厂(主要是凝气式汽轮机发电厂)的电能生产实质上是一个复杂的**能量转换**过程，主要由三大核心系统（三大主机）完成：

1. **燃烧系统（锅炉及其辅机）**：
   - **主要组成设备**：锅炉本体、输煤设备、制粉设备（如磨煤机）、送风机、引风机、除尘设备、排灰渣装置等。
   - **能量转换**：燃料的 **化学能 $\rightarrow$ 热能**。
   - **过程**：燃料（如煤粉）在锅炉炉膛内燃烧，释放出大量热能，将锅炉管壁内的水加热成高温高压的过热蒸汽。
2. **汽水系统（汽轮机及其辅机）**：
   - **主要组成设备**：汽轮机本体、凝汽器、凝结水泵、给水泵、循环水泵、高低压加热器、除氧器等。
   - **能量转换**：蒸汽的 **热能 $\rightarrow$ 机械能**。
   - **过程**：高温高压蒸汽通过管道导入汽轮机，在汽轮机内部膨胀作功，推动汽轮机转子高速旋转。作功后的乏汽排入凝汽器凝结成水，再由给水泵送回锅炉闭式循环。
3. **电气系统（发电机、主变压器及配电装置）**：
   - **主要组成设备**：同步发电机（含励磁系统）、主变压器、厂用变压器、各级配电装置（断路器、隔离开关、母线等）以及继电保护与监控系统。
   - **能量转换**：转子的 **机械能 $\rightarrow$ 电能**。
   - **过程**：汽轮机同轴带动同步发电机转子旋转。在励磁系统的作用下，发电机利用电磁感应原理将机械能转换为三相交流电能，随后经主变压器升压后并入电网。

**📌 核心能量转换链总结：**
$$ 化学能 \xrightarrow{锅炉} 热能 \xrightarrow{汽轮机} 机械能 \xrightarrow{发电机} 电能 $$

# 三、 火电厂的特点
分析火电厂的特点通常与水力发电厂进行对比：

- **优点**：
  1. **布局相对灵活**：建厂受自然地理条件限制较小，通常可建在靠近负荷中心或煤炭产地的地方，装机容量大小可按需要决定。
  2. **初期投资与工期**：与大型水电站相比，火电厂的建设周期较短，单位千瓦造价相对较低。
- **缺点**：
  1. **运行成本高**：燃料消耗量大，运行费用在发电成本中占绝对主导地位。
  2. **运行灵活性差（重要考点）**：火电机组启动和停机过程复杂且缓慢，尤其是冷态启动耗时长。负荷调节速度（滑压/定压运行）远不如水电机组快，调峰能力受限。
  3. **应当尽可能担负较均匀的负荷**：由于火电机组运行灵活性差且启停耗时长，频繁大幅度改变负荷会引起设备各部件（如锅炉、汽轮机转子）产生交变热应力，严重影响设备寿命和安全；同时，机组偏离额定工况运行时热效率会显著降低、煤耗增加。因此，在电网中火电厂通常宜承担较均匀的基荷。


  4. **对环境污染大**：燃烧化石燃料会产生大量的二氧化硫（$\text{SO}_2$）、氮氧化物（$\text{NO}_x$）、烟尘以及二氧化碳（$\text{CO}_2$）等温室气体，同时还会产生大量的灰渣，对大气和周边环境造成严重污染。
  5. **效率限制**：受限于热力学第二定律（卡诺循环），大量热能必然随冷却水散失，综合热效率偏低。

# 四、 火电厂对环境的影响
火力发电（尤其是燃煤）对环境的负面影响显著，现代火电厂必须配备庞大的环保设施：
- **大气污染**：燃烧产生大量二氧化硫（$\text{SO}_2$）、氮氧化物（$\text{NO}_x$）和烟尘。必须配备脱硫（FGD）、脱硝（SCR）和静电/布袋除尘装置。
- **温室气体排放**：燃烧化石燃料排放大量二氧化碳（$\text{CO}_2$），是造成温室效应的主因。目前正在发展碳捕集与封存技术（CCUS）。
- **水污染与热污染**：凝汽器需要海量冷却水，排出的温水会提高局部水体温度（热污染），破坏水生态系统；冲灰水及工业废水需要经过严格的污水处理。
- **固体废弃物**：产生大量粉煤灰和炉渣，需进行灰渣综合利用（如制砖、做水泥掺合料）或妥善存放，否则易造成二次扬尘和土地占用。
